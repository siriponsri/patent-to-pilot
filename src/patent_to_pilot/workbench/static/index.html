Mission

    Open run trace

    No result yet. Select Run comparison to run the local engine.

    Search

    Searches the current versions of this project's sources on this computer. No model or network is used. Each result is the exact stored passage; select Inspect source to open it in its source version.

    Compare

    Your requirements are checked against every candidate's current sources by the same local engine as the Workbench. When the first search leaves a visible gap (no match, a reference such as “ข้อ ๔(๒)” to another part, a missing field, or an item you mark as missing), the engine takes at most one extra step inside that candidate's own documents before it records the result. Each result shows that step as it was recorded.

    Requirements

    Add a requirement

    Write the requirement in your own words. The engine searches for the words and shows the best passage per candidate; it does not decide whether the passage satisfies the requirement. Thai text is kept as typed.

    Sources

    Current versions are searched. Historical versions stay readable for old citations.

    Add a document

    Plain text, Markdown (UTF-8) or a PDF with a text layer, up to 2 MB. The same name adds a new version of that source; results that depended on it are re-checked.

    Providers and execution mode

    Search, Compare and Inspect always run on this computer without any model or network. Optional models come from a self-hosted endpoint (a server you run) or an API provider. A profile is used only after its connection check passes. Keys are never entered here: a profile names an environment variable of the server process.
