# AM-7 stage 2a: ผลบน P1-DEV/VAL แบบอ่านง่าย (20 พ.ย. 2026)

ผลทั้งหมดในไฟล์นี้เป็นเชิงพรรณนาบน DEV/VAL ยังไม่ได้เปิด TEST และใช้งบ USD 0 (CPU กับ V100 ของ dr-train เท่านั้น)
ตารางเต็มอยู่ใน `stage2a-tables.md` และตัวเลขดิบอยู่ใน `stage2a-results.json`

## สรุป 4 บรรทัด

1. **Pipeline ถูกต้อง:** U0 บน E1 ได้ OUT R@200 = 0.3282 ตรงกับ Z-PatEmbed เดิมทุกตำแหน่ง
2. **Idea A แบบไม่ฝึกชนะ U0 ได้นิดเดียว:**
   - ตามกฎที่ freeze ไว้ A\* คือ A4′ = RRF(U0, co-citation)
   - MR@200 สูงกว่า U0 อยู่ +0.010 บน DEV และ +0.007 บน VAL
   - ตัวที่ได้ผลคือ co-citation ส่วน A1/A2 ซึ่งเป็นวิธีเวกเตอร์กลับแย่กว่า U0
3. **กลเม็ดง่าย ๆ ชนะทุกวิธี:** baseline N4 ที่แค่กดคะแนนเอกสารสาขาเดียวกับคำขอลง ได้ MR@200 = 0.370 บน DEV ส่วน A\* ได้ 0.322 ต่ำกว่าอยู่ −0.048 และบน E1 N4 ดัน OUT R@200 จาก 0.328 ขึ้นไป **0.383 (+0.054)** แต่ต้องแลกด้วย IN R@200 ที่ร่วงจาก 0.491 เหลือ 0.315
4. **Owner gate (AM-7 §6.4) ไม่ผ่าน:** ไม่มีวิธีใน stage 2a ที่ชนะทั้ง U0 และ N\* ได้ ≥ 0.010 ตามกฎจึงต้องหยุดถามเจ้าของก่อนจ่ายเงินขั้นถัดไป (A3)

## ความหมาย

- **ข้อที่ไฟล์รีวิว 11/12 เตือนไว้เป็นจริง:** OUT recall ถูกดันให้สูงขึ้นได้ด้วยการเลี่ยงเอกสารสาขาเดียวกันอย่างเดียว ข้อนี้กระทบทั้ง E2 และ endpoint เดิม (E1) เพราะ OUT R@200 วัดแยกจาก IN จึงให้รางวัลกับการ "หนีโดเมน" ถ้าไม่ได้ใส่ N4 ไว้ เราอาจรายงานผิดไปว่าวิธีใหม่ช่วย
- **Anchor มีข้อมูลจริง แต่น้อย:**
  - A\* ที่ใช้ anchor จริงดีกว่าตอนใช้ decoy อยู่ +0.012 และดีกว่า anchor ที่สลับมาจาก task อื่นอยู่ +0.014 ช่วงความเชื่อมั่นไม่คร่อม 0
  - แต่ขนาดผลเล็กกว่าผลของการกดโดเมนหลายเท่า
- **Co-citation ครอบคลุมไม่ถึงครึ่ง:** anchor มีประวัติถูกอ้างร่วมก่อนหน้าเพียง 45% ของ task (median ของ source action = 0) จึงช่วยได้แค่บางส่วน
- **P\* ไม่ต่างจาก U0:** P\* ซึ่งใช้ anchor ปลอมโดยไม่มีป้าย ได้ 0.3293 เทียบกับ U0 0.3282 ส่วน C4 (P\* − L\*) ติดลบ −0.053 เพราะ L\* คือ N4

## Power ของ TEST (ประมาณจาก DEV รวม design effect แล้ว)

| สมมติฐาน | MDE |
|---|---|
| D1 (A\* − U0) | ≈ 0.0087 |
| D2 | ≈ 0.0135 |
| C4 | ≈ 0.0093 |

D1 บน DEV ได้ +0.0104 ซึ่งพอตรวจได้แบบฉิวเฉียด แต่ D2 และ C4 ติดลบชัดเจน ถ้าเปิด TEST ตามแผนตอนนี้ D2 และ C4 น่าจะไม่ผ่าน

## สิ่งที่ยังรันอยู่

- Sensitivity ตาม AM-7.1 §7 รันต่อเองบน dr-train: A\* บน Qwen3 และ RRF(BM25, N5) ผลจะออกที่ `am7/stage2a-v2/sensitivity.json` บน dr-train
- รอบ stage2a-v1 ถูกหยุดเพราะช้า และไม่ได้อ่านผลจากรอบนั้น

## ทางเลือกที่ต้องให้เจ้าของตัดสินใจ

1. **หยุด Idea A ที่ stage 2a (ผมแนะนำ)**
   - ไม่จ่ายเงินให้ A3
   - เขียนผล stage 2a เป็นผลที่ตรงไปตรงมา
2. **ลอง A3 ต่อ (cross-encoder แบบมีเงื่อนไข ต้องขอเพดานงบใหม่)**
   - ตามกฎ A3 ต้องชนะตัวเดิมให้ได้ ≥ 0.010
   - แต่เพื่อจะผ่าน D2 ได้จริง ต้องชนะ N4 ซึ่งตอนนี้นำอยู่ 0.048
3. **ทบทวนโจทย์ของ Paper 1**
   - ผลนี้ชี้ว่า "OUT recall อย่างเดียว" เป็นเกณฑ์ที่หลอกได้
   - ถ้าจะเปลี่ยนเป็นเกณฑ์ร่วม เช่น OUT ต้องดีขึ้นโดยที่ IN ไม่เสีย ต้องเขียนเป็น amendment ใหม่ และต้องระบุชัดว่าเปลี่ยน**หลัง**เห็นผล DEV แล้ว
