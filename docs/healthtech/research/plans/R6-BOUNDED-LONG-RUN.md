## What changes prospectively

### Evaluator

Use the frozen evidence-ID critic rather than model-written literal quotes.
Exact references establish locations only. Separate execution failure, invalid
evaluator output, valid automated method flags and actual human decisions.
No old critic response is repaired, renamed or regraded into R5 success.

Freeze all24 authored calibration cases and labels before the first R6 model
output:10 nonidentical positives,10 critical contrasts,4 required uncertainties.
Require zero invalid responses, positive false flags, missed required verdicts,
unrelated flags or irrelevant required evidence. Parse raw responses; do not
accept self-reported VALID rows. Execution attestation is a separate prerequisite.
These exposed engineering fixtures do not estimate native accuracy. The first
qualified critic revision is frozen before native generation and retrieval.

### SACR

Each nonempty block's grammar and prompt permit only the full-source evidence
context; retain an independent coverage check. Reject gaps rather than
quietly losing difficult source content. Retain complete enclosing condition
context in the proposed selective view. Roles, attachment and selective-view
meaning remain unverified until fidelity gates pass. If compact equals anchor,
reuse the same vector and identify the duplicate control explicitly.
Preserve existing factorial arms, source-anchor and matched-coverage controls;
implement an explicit R6 component adapter, never silently substitute a different
retrieval method because legacy structures do not match.

### Structured/Graph: new partial-augmentation estimand

This requires explicit owner approval because R5 required full essential-source
coverage. The new claim is correctness of retained positive invention functions
and their necessary constraints, not complete extraction of every family function.
An empty result is ABSTENTION/zero extracted records, never a fidelity pass.
All100 fixed source families remain in coverage reporting;14 nonempty families
is a nonempty-family count, not measured functional recall. No resampling.

Retained-claim omissions of necessary conditions, wrong roles, negation or prior-art
attribution remain critical errors. Do not excuse them as low coverage. Use the
unchanged R2 records; no new corpus extraction or census is requested.

Alias predicate: both fixed witnesses assert the same positive technical action/
operand function with their individual contexts retained. It does not assert
device interchangeability or common operating ranges. Polysemy or negation can
invalidate the shared-function inference. Missing context requires uncertainty.
Attach complete fields for the fixed source/alias union of282 families from the
existing corpus, including183 alias families; retain hashes and exact witnesses.

S and G must use identical extraction, alias keys, scorer and candidate scope.
The posting-list implementation and one-key bipartite traversal are equivalence
controls. Do not claim graph-storage novelty or count identical results as two
independent improvements.

Freeze the operational scorer before new retrieval scores: unchanged dense B0
top200 plus exact query function-key matches from the unchanged extractor;
Map the existing curator-approved canonical query text used by B0 verbatim into
the R2 row's `abstract`, with `id=query_id` and empty `title`/`claims`; add no other
metadata or labels. Bind that text hash to the query manifest. Structured ranking
contains every positive-key-matched family in the existing45,336-family universe,
ordered by distinct matched keys descending, then family ID. No zero-match fillers
and no pre-fusion structured truncation are allowed.
Fuse by equal-weight RRF with constant60, deduplicate by the existing family ID,
return top200 with deterministic family-ID ties. S uses postings and G uses the
equivalent one-key traversal. Empty/unsupported query extraction uses B0 only,
retaining the complete query denominator. No new synonyms, learned weights or
score-driven tuning. Prove rank-for-rank S/G parity on fixtures and full dev.
