## Review findings fixed before model execution

The first draft calibration could pass by source equality plus blanket negatives.
It was rejected before any model output. Review also found a permissive-schema
mutation bypass, invalid Unicode acceptance and empty-pointer grounding. All
received regression checks. A disputed secondary alias gold label was removed:
preserved billing-fee context does not itself mean context was lost; the wrong
shared-function inference is the required defect. Source-only evidence was also
insufficient for quantity/attachment contradictions; candidate evidence is now
required in those cases. No historical outputs were salvaged to pass these tests.
