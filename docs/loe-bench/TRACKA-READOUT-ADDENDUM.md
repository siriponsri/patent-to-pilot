# Track A readout clarification for registration review

28 November 2026. This repository addendum documents a prospective implementation decision for [OSF registration P2SMD](https://doi.org/10.17605/OSF.IO/P2SMD). It is available for planner review before any outcome window matures. The filed registration and updates remain the source for the endpoint, arm assignments and analysis rules. [Review finding R3](reviews/EXTERNAL-REVIEW-R1.md#findings-table).

Use the **first published scored 12-month result** as the 12-month input for H3. Identify that result by the SHA-256 of the exact `results.json` bytes and the SHA-256 of its bound `outcome-source-manifest.json`. The manifest gives the FDA edition, URL, capture time and SHA-256 for each index and partition used. Record the scoring date and publication time in UTC. The canonical GitHub release holds the JSON, checksum, source manifest, report and draws. Its tag includes the exact Zenodo version record ID and the OSF U4 freeze-manifest SHA-256. The issue records the result and source-manifest digests.

At verified 24-month maturity, discover and verify the first publication before taking its 12-month estimate and interval. If its assets are missing or fail verification, apply the frozen 12-month endpoint and estimator to the covered 24-month snapshot and label the H3 estimate and decision `REVISED_VINTAGE`. Report the original scoring or publication date where documented, the original 12-month maturity, the revised scoring date and FDA edition, and the reason for use of the revised vintage. Use an unknown original date when the publication record cannot establish one. Keep any existing first report and its identifier. A GitHub transport or access error leaves the run available for operational retry.

H3 still uses the M3 minus B1 paired recall difference at 12 months. H1 and H2 must both pass at 24 months before H3 is reached. The registered one-sided level remains 0.025. The [measure map](TRACKA-MEASURE-MAP.md) records how the descriptive secondaries draw on the public freeze and which measures have unavailable inputs. [Score and preserve the readouts](HOW-TO-SCORE-TRACK-A.md).
