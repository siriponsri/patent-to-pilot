# Track A readout clarification for registration review

28 November 2026. This repository addendum documents a prospective implementation decision for [OSF registration P2SMD](https://doi.org/10.17605/OSF.IO/P2SMD). It is available for planner review before any outcome window matures. The filed registration and updates remain the source for the endpoint, arm assignments and analysis rules. [Review finding R3](reviews/EXTERNAL-REVIEW-R1.md#findings-table).

The **first verified published aggregate at each horizon** governs the whole Track A family, H1–H3, in the registered GitHub repository, Zenodo version DOI and OSF update 4 freeze-manifest scope. The default-branch **Score Track A** workflow fetches live FDA bytes at run time and is the canonical publication path. Standalone and caller-snapshot calculations are `PROVISIONAL` while that horizon awaits publication. Later calculations are `REPLAY` and report differences against the pinned aggregate. The first 12-month publication is descriptive and supplies the H3 input. Only the first published 24-month aggregate can carry a formal H3 decision. [Round 3 planner rule](reviews/EXTREV-RESPONSES.md#round-3-review-answered-28-nov-2026-2319-bangkok).

At 24-month maturity, discover the first 12-month publication in that scope. Compare the release notes, every trusted issue pin, asset checksums and embedded FDA manifest digest against the exact bytes. The manifest records the FDA edition, URL, time and digest of each input. An unresolved publication or local prior input gives `UNVERIFIED_INPUT`, with a descriptive H3 estimate and interval. A GitHub transport or access error leaves the run available for operational retry.

Use a `REVISED_VINTAGE` after canonical discovery records an absent release and tag and validates all surviving trusted scored issues. The discovery record gives the queried URLs, UTC times, scope, every trusted issue locator and its available pins. A malformed pin, missing result pin or conflicting witness gives `DISPUTED` and leaves H3 descriptive. With consistent absence, apply the frozen 12-month endpoint and estimator to the covered 24-month snapshot. The first 24-month aggregate binds the discovery record, original dates where available, original maturity, revised scoring date and FDA edition.

The release at each horizon holds the aggregate, checksum, FDA manifest, report and draws. Its tag includes the horizon, Zenodo record ID and freeze-manifest SHA-256. The scored issue and release notes pin all four content files. Retrieval preserves the first 24-month H3 vintage and safety results across FDA revisions and Actions artifact expiry.

H3 still uses the M3 minus B1 paired recall difference at 12 months. H1 and H2 must both pass at 24 months before H3 is reached. The registered one-sided level remains 0.025. The [measure map](TRACKA-MEASURE-MAP.md) records how the descriptive secondaries draw on the public freeze and which measures have unavailable inputs. [Score and preserve the readouts](HOW-TO-SCORE-TRACK-A.md).
