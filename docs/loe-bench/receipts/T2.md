## Design choices

- Start at `32b9da8a`. Use the existing NME at-risk cohort and first final original ANDA label with complete follow-up. Build annual January 1 rows starting in 2010. Choose the earliest validation start that allows at least one training cutoff and retain the longest eligible validation suffix. Every training window ends before validation starts, and every validation window ends before 2017-01-01. A horizon with no feasible split is `NOT_RUN`.
- Feature and graph inputs use the latest Orange Book edition on or before the cutoff, inclusive of the six-calendar-month floor. Keep eligible rows whose edition is stale, absent or lacks a matching product. Join the package ingredient key to NDA or legacy untyped products, then use application and product numbers to join patents and exclusivities. Exclude approval and patent submission records dated after the edition. Future expiry dates printed in that edition are available information. Count distinct listed patents. Use the signed interval to the last expiry and the elapsed interval since the earliest recorded patent submission. Compute the remaining time for NCE and other exclusivity separately, floored at zero. Encode unknown scalars as zero with explicit indicators. Matched products with no records have zero listing counts and zero remaining exclusivity. FIX1's graph interprets empty or incompletely dated clock evidence as unknown. The patent submission proxy supplies a numeric feature when present and leaves the challenge leaf unknown.
- M1 and M3 use the existing standardized L2 logistic regression with the same fixed defaults and numeric features. M3 adds one-hot Kleene verdicts. Fit sigmoid recalibration to their logit scores. For M2, a saturated verdict-only logistic table uses one positive and one negative pseudocount per verdict and falls back to the pooled smoothed probability for unseen verdicts. All three arms use identical validation calibration folds, assigned by the first eight SHA-256 bytes of the drug key modulo five. Score each fold with the other validation folds as the calibration pool. There is no parameter search. B1 retains the existing age table and 0.5 action threshold.
- Apply the package's fixed 0.25 and 0.75 cutoffs to M1 and M2. M3 uses those cutoffs in `evidence_graph.decide` with FIX1's default referral for a BLOCKED conflict. In each policy, rank covered rows by estimated probability of the emitted class. Compare no-entry counts on the same as-of OPEN rows to the original package ensemble, the mean of B1 and 200-epoch B2, with its OPEN policy at 0.25. Fit the ensemble on the same T2 training rows.
- Validate probabilities on all validation rows with Brier and 10 equal-width ECE bins. Report per-verdict Brier and row counts. Use FIX1's expected tie ordering and right-step risk curve, truncate to 80% and divide area by 0.80. A paired comparison requires both arms to reach 80%. For each evaluable pair, use 1,000 paired drug-key bootstrap replicates with seed `20261127`, retain finite deltas and report invalid draw counts with the 95% percentile interval. Deltas use M3 minus the comparator. CP2's useful effect is a delta at or below −0.010. The intervals condition on the fitted models and calibration predictions.

## Failures and limitations

- Cross-calibration holds out drug clusters within the validation period. Fitting and evaluating the calibration procedure within that period makes these development estimates. They cannot establish prospective generalization or confirm a useful effect.
- Orange Book ingredient matching, archived publication gaps, Drugs@FDA current-status history and unknown challenge evidence limit interpretation. The outcome is an approval proxy for market entry. B1 and B2 retain their package definitions and the historical package OPEN example uses a different cohort.
- At 36 months the latest admissible validation cutoff is 2013-01-01. The earliest training window, starting on 2010-01-01, ends on that same date and fails strict embargo. Backfill cannot resolve this split constraint.
- The first development invocation used B2 alone for the supplemental OPEN comparison. A source check identified the original age-table and logistic ensemble. The final invocation uses the ensemble; both invocations yielded zero eligible OPEN rows. The main arm fits and AURC protocol stayed the same.
