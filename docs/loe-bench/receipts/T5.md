## Open fields and handoff

- **Before OSF submission:** Owner fills authors/contributors, OSF subjects and registration licence. Authors complete their individual prior publications/dissemination and access disclosures. Main planner adds the reviewed T4c statistical power and type-I summary and replaces `[T4c RULE_SELECTED_ALPHA]` under the fixed v3 rule. This draft leaves it open as dispatched.
- **Before confirmatory release:** Independent custodian supplies the C′ PASS/FAIL verdict. Main planner reviews the documentation, settles L1 configuration and authorization or records it NOT_RUN, and coordinates prospective G3b packaging and timestamping. The owner submits to OSF and downloads the registered PDF. The main planner writes its digest into the lock after submission. Owner-authorized runs then use the same digest.
- **Review choices:** The draft reports both LF and CRLF frozen configuration digests, uses stage-specific configuration counts, and leaves AUGRC as an unadopted reporting idea. It retains the strict young-cohort sensitivity while following REG's correction to the premise about NME versus NCE. No tests or scoring were run for this documentation change.
