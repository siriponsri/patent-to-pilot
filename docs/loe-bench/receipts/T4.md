## Protocol before simulation

The aim is to estimate operating characteristics before preregistration. Follow the [ADEMP framework](https://pmc.ncbi.nlm.nih.gov/articles/PMC6492164/) of Morris, White and Crowther (2019, doi:10.1002/sim.8086) and the [owner-approved sequence](../PLAN.md#confirmatory-criteria-v2-main-planner-proposal-owner-approved-27-november-2026).

- **Data generation.** Fit the shared active-moiety history, event timing, score and abstention inputs on eligible development cutoffs. Count the candidate test frame from NDA approval and dated NME features, with complete follow-up determined by the pinned S0 date. The test-period count excludes the generic outcome stream and cannot establish the final at-risk population. Use synthetic annual histories, one event time per drug, and correlated cluster and row noise. Vary event clusters, prevalence, age mix, score correlation and coverage.
- **Estimands.** H1 compares M3 with B1 at 24 months, H2 compares M3 with M1 at 24 months, and H3 compares M3 with B1 at 12 months. Calibrate the three population differences to zero and to −0.010. Check the targets on independent large synthetic samples. Include two mixed nulls at the reference design to inspect the sequence when the first true null comes later.
- **Methods.** Use FIX1 expected tie ordering and normalized right-step AURC on common 0–80% coverage. Use paired whole-drug bootstrap draws and the existing 97.5th percentile index. A bound strictly below zero rejects. Apply H1, H2, H3 in order and stop on the first non-rejection or unevaluable contrast. Drop nonfinite bootstrap differences and record them. Simulate 5,000 datasets per main scenario and configuration. For runtime, use 120 draws per main replicate and compare the decisions with 2,000 draws on a prespecified reference subset. Use separate random streams for calibration, validation and assessment.
- **Performance.** Report unconditional rejections, earlier-step conditional rejections, coverage failures, Wilson 95% Monte Carlo intervals, and H1's 80%-power effect estimated by shifting the reference bootstrap upper-bound distribution. Use the smallest tested event-cluster count with at least 80% estimated H1 power at −0.010. Report bounds or unattainable targets where the grid or generator lacks support.

## Inference and reproduction

Use the same cluster weights for each arm in a horizon. Separate horizon resamples estimate the per-step intervals on the same synthetic study population. Compute exact expected tie-prefix risk by integrating per-bin fractional errors and a harmonic sum. This is the FIX1 right-step curve evaluated with cluster multiplicities, including a partial step at 80%. Coverage failure on the observed data prevents a rejection. The 97.5th empirical percentile uses finite draws and the T2b order-statistic index. No finite draws means the contrast is unevaluable. Track marginal rejections as diagnostics and use the intersection of earlier rejections for overall fixed-sequence power. Each conditional estimate uses the runs reaching that step, including coverage failures there as non-rejections.

The reference scenario uses the same initial 120 draws within each 2,000-draw check on the first 400 null and first 400 useful replicates. The main grid uses 5,000 datasets per scenario under each effect configuration. The 75-cluster reference adds 5,000 datasets with H2 null and 5,000 with H3 null. Those mixed configurations estimate the chance of rejecting the first true null after its predecessor succeeds. Under the global null, H1's rejection rate is the family-wise type-I error. The intervals measure Monte Carlo uncertainty for these simulated conditions.

## Failures and limitations

- Static inspection identified an unguarded reader in the historical linker. Interrupting the shell returned exit 1 but left its Python tree active. The process tree subsequently showed that the initial preflight had reached synthetic simulation, which confirms that its linker had decoded the mixed-period public ANDA application records. That linker used only application numbers and types from those records. The preflight produced no outcome output or test metric. The final runner projects both event-source readers, and the test fixture inspects the payload that reaches the JSON decoder. The seal source remained unchanged, and the preregistration lock and environment variable were absent. The main planner should account for the source-read incident at review.
- Development regression tests initially caught floating-point cluster totals reaching integer harmonic indices. A small independent calibration test also had excessive Monte Carlo variation. The corrected code converts integer-valued counts before indexing and uses a larger verification sample in the fixture. A subsequent preflight was stopped to correct NumPy scalar serialization before the final run. None of the preflights produced a result file.
- While investigating duplicate CPU use, one local Python worker (PID 27976, parent 12176) was stopped before its parent had been matched to the T4 command line. Its task ownership was unverified. The initial T4 process tree was then identified by the exact runner command and terminated by its verified parent and child process IDs.
- The synthetic cluster total uses the NDA feature inventory. The confirmatory at-risk cohort excludes prior ANDAs and may be smaller with a different follow-up distribution. Test event prevalence, event-cluster count, score distributions and coverage remain unknown. The CP2 requirement of 50 actual event clusters and the fresh-edition gate remain in force.
- The generator simplifies cross-arm calls, the tie structure, E7's unmeasured behavior and the baseline relationship between H1 and H2. Estimates condition on these frozen assumptions and the imposed population effects. The event count threshold is specific to the tested grid. The H1 MDE is a location-shift estimate around −0.010 and can move when abstention, tie patterns or estimator variance change with the effect.
