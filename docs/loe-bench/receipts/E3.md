FDA terms: the FDA website policies page states that contents of www.fda.gov are in the public domain and may be used freely without permission; credit to FDA is appreciated. The page has no automated-download prohibition. The CSVs live on `accessdata.fda.gov`, which I did not check separately. Downloads were sequential with a 0.7 s pause and a descriptive User-Agent that names the contact email.

Authoritative source: the Purple Book monthly files. They list every FDA-licensed biological product with BLA type (351(a) or 351(k) Biosimilar or Interchangeable), reference product, submission type and approval date. In the October 2026 file all 261 rows of 351(k) products have Center = CDER. CBER coverage of 351(k): none appears. CBER appears only for 351(a) products. openFDA and the web chart are secondary.

Counts from the 2026-10 file (2,270 parsed rows): 96 distinct 351(k) BLAs (79 Original rows typed Biosimilar, 114 typed Interchangeable, plus 68 supplement rows; rows are product presentations). The union over all 74 parsed months gives the same 96, so no 351(k) BLA dropped out of the listing since April 2020. They map to **21 reference products** (proper-name level); every reference product matched a 351(a) BLA, 8 of them to more than one reference BLA (pipe-joined in the CSV).

Outputs: [trackB_first_biosimilar.csv](../../../loe-bench/data/trackB_first_biosimilar.csv) (reference product, reference BLA, first biosimilar BLA, proprietary name, first approval date, n biosimilar BLAs, n BLAs listed Interchangeable). First approval = earliest Original-row approval date per BLA. Spot check: filgrastim to Zarxio 2015-03-06, infliximab to Inflectra 2016-04-05, pegfilgrastim to Fulphila 2018-06-04, adalimumab to Amjevita 2016-09-23, all as expected. Raw CSVs are in `_private_artifacts/loe-bench/purplebook/`.

Parser bug fixed in `purplebook.py` (test `test_purplebook.py`, 2 tests pass): FDA renamed columns in some releases ("License Type" for "BLA Type", "Marketing Status"; Aug to Oct 2023 and Oct 2026), so `biosimilar_entries` returned 0 rows on the newest file. Some files are cp1252, not UTF-8, so `read_pb_text` was added.

## Failures and limitations

- Months not usable: 2020-01 (404, no Wayback copy), 2020-02 and 2020-03 (legacy layout without the N/R/U header; 2020-03 is a small file with a different structure, 2020-02 is not saved), 2026-11 (not yet published). The parser reads 74 months, 2020-04 to 2026-10. Listed in `missing_or_unparsed_months`.
- The 2020-04 file holds only 90 rows (changes only). Full snapshots begin 2020-05.
- `Date of First Licensure` is blank for 351(k) rows, so the approval date comes from the Original row. A BLA with several presentations has several Original rows; the earliest is used. Not verified against the FDA web chart.
- Withdrawn or delisted biosimilars: the Purple Book keeps the status, but a product removed before April 2020 is not seen. Pre-2020 history needs older monthly files or FDA archives; not attempted.
- Reference-product matching is by proper name (lowercase). Multi-BLA references (8) need an owner decision on which BLA is "the" reference. The CSV is descriptive; no modelling was done.
- `purplebook.fda.gov` was not reachable by DNS from this machine; it may be a network issue here. Monthly CSV bytes were not independently checked against the FDA web chart.
- Row counts count parsed product-presentation rows, not distinct products.
