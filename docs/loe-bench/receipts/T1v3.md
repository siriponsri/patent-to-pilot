Each arm ranks every eligible row by native probability, before calibration and graph actions. For each cutoff allocate exactly floor(N/5) slots. At the boundary, each tied row has inclusion probability equal to remaining slots divided by tied rows. Pool expected event hits over total event rows for recall and over slots for precision. For each event drug compute the probability of at least one positive row entering a queue, assuming independent lotteries across cutoffs. Sum these probabilities and divide by distinct event drugs.

Use NumPy default_rng seed 20261127 per horizon and 2,000 common draws for levels and paired differences. Sample as many whole histories as observed drugs, with replacement. Each sampled copy contributes each of its years, and repeated copies count separately in the drug capture statistic. Recompute cutoff sizes, capacities, ranks and ties per draw. Use 95% percentile intervals. Any undefined replicate renders its interval unevaluable and fails the defined-endpoint gate. Report H1 (24m M3−B1), H2 (24m M3−M1), H3 (12m M3−B1) and all three arm contrasts at both horizons for development description.

Use the 2010-01-01 inner TRAIN slice for all arms. Produce five-fold out-of-fold raw probabilities with the inherited SHA-256 drug partition. Exclude each held fold across all TRAIN rows. Fit one sigmoid per arm and horizon on clipped out-of-fold logits and TRAIN outcomes. Select the lowest observed threshold hi whose actual flags fit floor(N/5), keeping score ties together. If no observed candidate fits, use 1.0. Choose the largest observed threshold lo below hi whose nonempty clear set has at most 1% events, or 0.0 if none exists. Freeze both thresholds and the sigmoid before scoring validation. Fit the final native models on all TRAIN rows.

Clear at p ≤ lo, flag at p ≥ hi, and refer intermediate risk. Apply the graph decision for M3 with those thresholds, including referral of BLOCKED conflicts. Require p ≤ lo to clear BLOCKED rows as well. Count flag capacity using actual emitted flags. The inner flag target fixes the score threshold. Realized flag and referral workload on validation are reported with no threshold adjustment. The primary queue enforces its capacity independently.

Evaluate the conditional missed-clear rate with a conservative two-sided 95% Chernoff interval. Scale each drug's missed-row count by the largest number of clear rows for any drug. The resulting independent drug variables lie in [0,1], with arbitrary dependence within each drug. Their sum's moment-generating function is bounded by that of a Poisson variable with equal mean. Invert both tails at 0.025 and divide the rescaled limits by the fixed observed clear count. For zero misses the upper limit remains positive. No clears makes safety unevaluable. The interval conditions on validation's clear roster and on the fitted policy.

Freeze as FROZEN_FOR_PREREG only when every queue fills its exact cutoff capacity, each arm and horizon has a validation missed-clear upper bound ≤ 3%, and the pooled endpoint computations are defined. Save the evaluated configuration and failure reasons as FAILED_DEVELOPMENT_ACCEPTANCE otherwise.
