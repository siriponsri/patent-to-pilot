# CP3 · Which changes could improve selective risk?

Try a graph-policy ranking change first. It can test the incremental value of the graph with the existing evidence and probability fit. The next cheapest shared change is to count distinct reference-product presentations in the historical Orange Book. Both are hypotheses. The only LOE-Bench comparisons below come from the existing development receipts.

At 24 months, FIX2c reports M3 minus B1 of −0.007230 (95% CI −0.016242 to +0.001034) and M3 minus M1 of −0.000135 (−0.001453 to +0.001101). There were 1,083 validation rows, 561 drug clusters, 67 event clusters and only 10 OPEN rows. Those intervals condition on development selection. A model change shared by M1 and M3 could help H1 while contributing little to H2. The 24-month H1 comparison precedes H2 under criteria v2, followed by H3 at 12 months. Each arm must reach 80% coverage. Report practical relevance against −0.010 separately. [FIX2c](receipts/FIX2c.md) · [Criteria v2](PLAN.md#confirmatory-criteria-v2-main-planner-proposal-owner-approved-27-november-2026)

## Ranked development candidates

Rank reflects plausible benefit per implementation and evidence cost. All IDs below are proposed for the planner's ledger. None has been tried in CP3. B1 remains the frozen comparator. Costs are engineering estimates for a small stdlib implementation, excluding review.

| Rank and ID | Change and comparison | Why it might move AURC80 | Cost, failure mode and decision |
|---|---|---|---|
| 1 · K06 | M3 policy only. From the probability of the emitted class, subtract 0.05 once if any UNKNOWN leaf is decision-relevant. A leaf qualifies if two completions differing only in that leaf can change the root while holding all observed leaves fixed. For M1 use the same fixed discount for any missing raw clock or challenge input. Compare each with its current undiscounted confidence. | A missing challenge cannot change a hard exclusivity block. The graph can distinguish this case from an unresolved blocker. The discount can reorder nearby cases even when no probabilities tie. Both arms keep their original actions and coverage. | Low, about half a day. Enumerate the three-leaf truth table. The five-point discount is a proposed engineering constant, without an effect-size basis. A nearly constant flag or a weak relation to error could yield no benefit. Never resolve a leaf from a later filing. No new source. [Risk Advisor](https://link.springer.com/article/10.1007/s10994-022-06248-y) · [Current graph](../../loe-bench/loe_bench/evidence_graph.py) |
| 2 · K07 | Both arms. Count distinct NDA strengths within normalized form/route and count distinct form/route pairs for the entity at cutoff. Retain current oral/injectable flags and prior NDA count as controls. | Breadth of marketed presentations could proxy demand or formulation difficulty before entry. Distinct product rows or application counts alone conflate manufacturer, pack and presentation. The expected direction for breadth is uncertain. | Low to medium, 1–2 days. Use FIX2c-linked NDA products in a fresh, availability-proven edition. Collapse duplicate presentations, preserve units and combinations, flag ambiguous or missing fields in both arms. Never count later strengths, ANDAs or products first seen after cutoff. No new source if historical members contain the fields. [FDA product columns](https://www.fda.gov/drugs/drug-approvals-and-databases/orange-book-data-files) · [Hu workshop, slides 16–18](https://www.fda.gov/media/108577/download) |
| 3 · K08 | Both arms. Fit a small selector for error of the **emitted action** using out-of-fold predictions. Start with emitted-class confidence and its absolute disagreement with the TRAIN age-clock probability for that same action. Rank by lower predicted error, keeping each arm's action fixed. | Two equally confident calls can have different risks when the regulatory features and age clock disagree. Unlike a monotone transformation of confidence, disagreement can reorder covered calls. M1 receives exactly the same selector design, inputs and search allowance. | Medium, 1–2 days with the logistic fitter. Generate paired out-of-fold actions and base scores without fitting B1, calibration or the selector on the held drug. Respect label maturity. Too few mistakes in the fit slice can collapse the selector to the baseline. No new dependency. [Risk Advisor, failure-risk experiments](https://link.springer.com/article/10.1007/s10994-022-06248-y) |
| 4 · K09 | Both arms. Fit pooled discrete-time logistic hazards in two annual intervals after each eligible landmark. Freeze covariates at the landmark, allow an interval intercept, retain the shared age-base information. The 24-month probability is one minus the product of the two conditional survival probabilities. Compare with current direct horizon fits. | The second-year event risk is conditional on no first-year approval. Pooling slope estimates across intervals can borrow strength and enforce coherent 12/24-month risks. A finer grid may be unstable. | Medium, 2–4 days for expansion, fit and censoring fixtures. Enter interval two only while event-free. Retain completed event-free intervals before censoring, omit incomplete event-free intervals, stop at the first final approval. Keep one prespecified weight scheme for overlapping landmarks and resample whole drug clusters. No new library. [Nnet-survival, likelihood](https://arxiv.org/abs/1805.00917) · [Hu submission model](https://pubmed.ncbi.nlm.nih.gov/31009066/) |
| 5 · K10 | Both arms. Compare the current Platt-style sigmoid on logits with one monotonically constrained beta-calibration map. Use identical folds, fitting loss and configuration counts per arm. | A third parameter can correct asymmetric tail errors and change actions near 0.25 or 0.75. Within either fixed predicted class a strictly monotone map preserves order. AURC improvement needs changed actions, covered membership or ordering across action classes. | Low, about one day. Fit the logit of calibrated risk as c + a log(p) − b log(1−p), with a,b nonnegative, common clipping and an identity fallback fixed before fitting. Sparse events may favor the existing sigmoid. No new library. [Beta calibration, method and experiments](https://proceedings.mlr.press/v54/kull17a.html) · [Current cross-calibrator](../../loe-bench/loe_bench/t2.py) |

**Comparison contract.** Keep the K01 historical protection features, K02 age base, K03 entity key and K04 challenge-source work in their assigned lanes. K05 already covers regularization. T2b already uses a sigmoid calibrator. Freeze one candidate at a time, tied-score handling, fallbacks, tuning count and eligibility before scoring. For K06, freeze the same two configurations per arm (zero or five-point discount) and retain the flat missingness control. The discount is a ranking score adjustment only. Give both arms the same new underlying evidence. Report the within-M3 policy ablation as well as the matched H2 contrast. [Ledger](TECHNIQUE-LEDGER.md) · [T2b design](receipts/T2b.md)

For new fitted selectors or calibration maps, separate fitting, policy selection and evaluation. Use development-only forward splits with label windows ending strictly before the next partition and keep each held drug outside nuisance fits. If too few eligible folds or events remain, record infeasibility. Apply probability calibration before deriving actions. Audit the error ordering among emitted actions at the same coverage and retain the existing tie-aware AURC calculation and paired drug-cluster bootstrap. Record errors by action and the count of distinct policy scores to distinguish a rank change from a change in referral rate. Neither exposed aggregate results nor later source releases can choose a configuration. [Protocol](PLAN.md) · [Scoring and action rules](receipts/T2.md)

## What previous generic-entry studies predicted

| Study and observed endpoint | Inputs, model and relevance to a 24-month first final approval |
|---|---|
| Hu et al., CPT 2019, DOI 10.1002/cpt.1479 | Time from earliest lawful filing to **first ANDA submission** for new chemical entities. Random survival forest versus Cox regression using product, regulatory and economic variables. The abstract reports internal and external validation. Hu's earlier workshop names sales, product-specific guidance availability and active-ingredient complexity. Its sales window is aligned to the later submission, an inadmissible look-ahead at our annual cutoff. Historical as-of replay in the article is unverified. [Article abstract](https://pubmed.ncbi.nlm.nih.gov/31009066/) · [Workshop, slides 15–18](https://www.fda.gov/media/108577/download) |
| Beall, Darrow and Kesselheim, Value in Health 2018 | A deterministic clock used a term-restored patent when available, otherwise the earliest-expiring listed patent, with pediatric extension, other exclusivities and patent type. The comparison used Medicaid-observed entry for 170 top sellers losing exclusivity in 2000–2012. The median was close overall but the method substantially overpredicted exclusivity in the secondary-patent subgroup. A cohort selected for eventual entry omits the still-at-risk denominator. Useful clock benchmark, different endpoint and metric. [Methods and results](https://pubmed.ncbi.nlm.nih.gov/30502781/) |
| Beall, Darrow and Kesselheim, JLME 2019, DOI 10.1177/1073110519840499 | Page 177 describes their prior 170-drug study and its use of patent expiry, patent-term restoration and pediatric exclusivity to approximate market arrival. Treat it as an explanation of the clock. Independent model fitting, out-of-time validation and any new performance estimates are UNVERIFIED. [Publisher record](https://www.cambridge.org/core/journals/journal-of-law-medicine-and-ethics/article/abs/approximating-future-generic-entry-for-new-drugs/56765AF1008397172510060B253281D9) · [Page 177, right column](https://static.cambridge.org/content/id/urn%3Acambridge.org%3Aid%3Aarticle%3AS1073110500021999/resource/name/firstPage-S1073110500021999a.jpg) |
| Scott Morton, NBER working paper 6190, and Grabowski & Vernon, JLE 1992 | Scott Morton studied firms' decisions to enter using 1984–1994 approvals, firm experience and market characteristics. Larger revenue markets attracted more entrants. This motivates a lagged demand proxy but supplies no estimate of its accuracy for first final approval. Grabowski & Vernon's study concerns brand loyalty, entry and prices after the 1984 Act. Duke confirms the citation. Its fitted specification was not verified here. [Scott Morton, abstract](https://www.nber.org/papers/w6190) · [Grabowski & Vernon, DOI 10.1086/467257](https://scholars.duke.edu/publication/665425) |

## Other methods and reasons to defer them

| Proposed ID and comparator | Potential use, implementation cost and constraint |
|---|---|
| K11 · Economic demand, both arms versus K07 | Use log gross brand spending or prescription volume in the latest released observation window, with age of data and suppression flags. CMS's **21 December 2015** Medicare dashboard used 2014 observations and included only 40 Part D drugs. At 1 January 2015 even those rows are unavailable. The **14 November 2016** Medicaid launch describing 2015 spending is too late for the last development cutoff. Medicaid SDUD is an alternative with a documented example of delayed publication. Spending is payer-specific, affected by coverage and prices, and absence from a selected dashboard cannot mean zero. Medium to high cost, several days for exact-vintage archives, open reuse terms, brand identity mapping, period alignment and suppression checks. Owner decision on a new source. Admit only files with a pre-cutoff public release witness and usable TRAIN coverage, otherwise park. [Medicare release](https://www.cms.gov/newsroom/fact-sheets/medicare-drug-spending-dashboard) · [Medicaid release](https://www.cms.gov/newsroom/fact-sheets/medicaid-drug-spending-dashboard) · [SDUD posting notice](https://www.medicaid.gov/medicaid/prescription-drugs/state-drug-utilization-data) · [Entry incentives](https://www.nber.org/papers/w6190) |
| K12 · Competing risks, both arms versus K09 | Estimate a separate conditional hazard for first ANDA approval and each mutually exclusive absorbing cause, then accumulate approval probability using survival from **all** causes. A withdrawal of one strength, commercial discontinuation or challenge does not establish entity-wide impossibility of approval. Administrative end of observation is censoring. With no verified absorbing event and date, retain single-event K09. High cost to validate an event taxonomy, moderate stdlib multinomial fit. Owner decision before new labels or sources. DeepHit is an external competing-risk reference, with no local deep-network trial. [DeepHit, problem formulation](https://cdn.aaai.org/ojs/11842/11842-13-15370-1-2-20201228.pdf) |
| K13 · Isotonic and inductive Venn–Abers versus the current sigmoid, both arms | Isotonic calibration pools adjacent violations into increasing steps. Cheap stdlib implementation, but sparse steps induce confidence ties. Inductive Venn–Abers fits isotonic maps after appending each hypothetical binary label for the new point. Its two outputs express ambiguity in assigning a probability. A wider pair could flag a fragile prediction for referral. Moderate cost for repeated fits. Apply identical pooling, smoothing choices and folds to both arms. Never append the true held outcome. Exchangeability-based validity is unverified across eras and repeated drug cutoffs. [Platt versus isotonic experiments](https://www.cs.cornell.edu/~alexn/papers/calibration.icml05.crc.rev3.pdf) · [Inductive Venn–Abers](https://arxiv.org/abs/1511.00213) |
| K14 · Conformal risk control versus fixed confidence thresholds, both arms | A threshold can choose an operating point with a calibrated risk target. It does not improve a fixed ranking by itself. Classical CRC requires exchangeability and a monotone loss. The empirical error fraction among accepted predictions can rise or fall as coverage changes. Do not apply the theorem directly to that ratio. Low computation, substantial design cost to specify a suitable risk bound and justify sampling under temporal drift and clustering. Keep as a secondary operating-point study. [Angelopoulos et al., assumptions and loss](https://arxiv.org/abs/2208.02814) |
| K15 · Selective calibration and verdict-specific error estimates versus K08 | A well-calibrated overall probability may be unreliable within a selected subset. For both arms audit accepted-set calibration at fixed coverage. For an M3 policy variant, shrink verdict-specific **action-error** offsets toward the shared selector with a fixed penalty and pooled fallback. Keep the event-probability calibrator shared and offer M1 the same policy-fit budget with a raw missingness stratum. The 10 OPEN validation rows make stand-alone OPEN calibration unattractive. Low code cost, high variance, held-drug labels excluded from fitting. [Calibrated Selective Classification, selector objective](https://arxiv.org/abs/2208.12084) · [FIX2c](receipts/FIX2c.md) |
| K16 · Learning to defer, both arms versus confidence referral | Optimize whether an analyst or the model should decide, using actual analyst decisions and independently adjudicated outcomes. Expected benefit is lower combined decision error if analysts can resolve cases the model misses. Review effort and selective observation of referred cases confound evaluation. Model fitting is moderate in stdlib, but paired reviewer outcomes on a representative sample are missing. Owner decision for new reviewer data. Never substitute an oracle or count abstention as a correct answer. [Mozannar & Sontag, expert-decision training](https://arxiv.org/abs/2006.01862) |
| K17 · Cost-aware evidence acquisition, M3 workflow versus checklist | Existing code suggests a leaf and reports information gain. Instead prioritize expected reduction in decision loss per review minute, allowing an unresolved document return. Use dated as-of evidence-search logs for yield and time. With equal review budgets compare cost per resolved case and resolution quality. Keep this separate from confirmatory AURC80 and H2. Moderate stdlib engineering, high evidence cost. Owner decision if collecting review traces. Without observations of available evidence and retrieval cost, leave the gain unestimated. [Prediction-time acquisition, pp. 1–2](https://prem-melville.com/publications/afa-nips08.pdf) · [Existing planner](../../loe-bench/loe_bench/voi.py) |

## Reusable software and data

These are implementation references and named workflow comparators. No code or dataset was imported, installed or benchmarked. The source register pins the inspected README and licence bytes. A software licence alone does not license every upstream dataset.

- **charlesduan/orangebook** (MIT). Python Orange Book and PTAB analysis. The README describes retrieving historical editions after records disappear from current files. Useful as an independent parsing reference for K07. A folder name alone cannot prove a ZIP was public at cutoff. [Pinned README](https://raw.githubusercontent.com/charlesduan/orangebook/19ca11f35ce6b9cb44d08499f627abc9002e8b6f/README.md) · [Licence](https://raw.githubusercontent.com/charlesduan/orangebook/19ca11f35ce6b9cb44d08499f627abc9002e8b6f/LICENSE.md)
- **QuentinCody/fda-purple-book-mcp-server** (Apache-2.0). Purple Book parser for biological products. Its README distinguishes monthly changes from the complete snapshot and preserves multiple presentations under a BLA. Useful for Track B parser fixtures. FDA monthly downloads are the source of record. Track B remains descriptive. [Pinned README](https://raw.githubusercontent.com/QuentinCody/fda-purple-book-mcp-server/37767dd0cd9902d4b0676b3e0ab9440fb43ed547/README.md) · [Licence](https://raw.githubusercontent.com/QuentinCody/fda-purple-book-mcp-server/37767dd0cd9902d4b0676b3e0ab9440fb43ed547/LICENSE)
- **topaisaas-dev/pharmapatent-expiry-api** (MIT). Patent-cliff monitoring API. The README describes expiry and Paragraph IV lookup. Use its workflow as an external comparator for date lookup only. No reproducible as-of first-approval forecast, outcome validation or AURC comparison was verified. [Pinned README](https://raw.githubusercontent.com/topaisaas-dev/pharmapatent-expiry-api/877acf6a2ca68d2ad0101221d165d6374c0027c1/README.md) · [Licence](https://raw.githubusercontent.com/topaisaas-dev/pharmapatent-expiry-api/877acf6a2ca68d2ad0101221d165d6374c0027c1/LICENSE)

The FDA product file defines strength and dosage form/route, and the Purple Book supplies monthly downloadable files. Rights and public availability must travel with the exact source edition before reuse. No third-party licence or current snapshot establishes historical availability. The top five require no new dependency. NumPy acceleration, LightGBM, any new data source or a change in confirmatory design should be presented to the owner before adoption.
