# U.S. regulatory rules in LOE-Bench

**REG executor verification, 27 November 2026.** Audited code and owner-package assumptions at base `3f6482237fbc03d3a174bf0c09d1d33b0208dccb`, with the E7 correction described below. This is a primary-source desk check for forecast triage. It is not legal advice, a freedom-to-operate opinion, or independent expert adjudication. The endpoint is a first final FDA approval in the defined group. Actual commercial launch is a separate event. The engine does not model litigation outcomes, settlements, at-risk launches or authorized generics. ## Disposition for integration

The E7 change is limited to matched records without a usable date. A dated FDA or court witness can still establish positive evidence. Fresh-list non-observation remains a forecast proxy. Tests cover an FDA `pre-MMA` row and a blank date. The open flags change either the defined comparator, the feature contract, the endpoint wording, or the evidentiary interpretation. They are recorded here for the planner before the protocol freeze. Any further change that alters predictions needs a predeclared development-only check and a versioned comparator or feature contract as applicable. Report the absence of expert adjudication in the manuscript.

The owner package is design evidence, cited by path and line, with its original Thai preserved. Git blob IDs at the audited base are `20ddc67b6ba206a19de1be851363f09c4f870837` for 05 and `92822b80db6b14072b0861a403c5b01312223bf2` for 09. This audit covers U.S. assumptions in those documents. Thai patent practice, commercial reuse rights and institutional ethics determinations sit outside this regulatory code audit.
