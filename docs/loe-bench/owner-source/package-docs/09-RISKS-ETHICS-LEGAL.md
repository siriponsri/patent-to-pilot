# 09 — ความเสี่ยง จริยธรรม และข้อกฎหมาย

## ความเสี่ยงงานวิจัย
| ความเสี่ยง | ผลกระทบ | การลดความเสี่ยง |
|---|---|---|
| Age-clock baseline (B1) แข็งอยู่แล้ว (smoke: AUROC 0.771) | ชนะยาก | ตรึงเกณฑ์ล่วงหน้า; ถ้าแพ้ รายงานผลลบ/เปลี่ยนเป็น dataset paper |
| ไม่มี patent ย้อนหลัง (G1) | ข้อเรียกร้อง FTO อ่อน | Track A prospective + ระบุ limitation |
| Track B n เล็ก | ไม่มีนัยสถิติ | รายงานเชิงพรรณนา |
| ใช้ ANDA approval แทน launch | คลาดเคลื่อนกับตลาดจริง | ระบุชัดเจนว่าเป็น proxy |
| Prior art ซ้ำซ้อน | reviewer ปฏิเสธ | อ้างครบ (10) และจำกัดข้อเรียกร้องความใหม่ |
| Paper 53 ยังไม่ผ่านการตรวจซ้ำอิสระ | ความน่าเชื่อถือการอ้าง | อ้างเป็น motivation และให้ IS2 ยืนหยัดเอง |
| ทำคนเดียว ไม่มี expertise | error ที่มองไม่เห็น | task card + acceptance test + ผู้เชี่ยวชาญรีวิว 1 คน |

## ขอบเขตกฎหมาย
- ผลลัพธ์เป็น **การจัดลำดับความสำคัญ (triage)** ไม่ใช่ความเห็นทางกฎหมายหรือ FTO opinion; ต้องมีข้อความปฏิเสธในทุกผลลัพธ์
- กฎหมายและวิชาชีพที่เกี่ยวกับการให้ความเห็นสิทธิบัตรในไทย: **ไม่ทราบ** → ตรวจก่อนขายบริการ
- ข้อสมมติด้าน exclusivity (NCE 5 ปี, biologic reference 12 ปี ฯลฯ) ต้องให้ผู้เชี่ยวชาญยืนยัน
- เงื่อนไขการใช้ข้อมูล: openFDA/Purple Book เป็นข้อมูลสาธารณะ แต่ให้ตรวจ terms ก่อนจำหน่ายต่อ; ข้อมูลที่ scrape ผ่านบริการ ให้ตรวจสิทธิ์ก่อนใช้เชิงพาณิชย์

## จริยธรรม
- ไม่ใช้ข้อมูลผู้ป่วย ไม่ต้องขอ IRB สำหรับข้อมูลสาธารณะระดับยา (ให้ยืนยันกับสถาบัน)
- รายงานผลลบ ไม่ปรับเกณฑ์หลังเห็นผล
- เปิดเผยการใช้ AI ช่วยเขียนโค้ด/ร่างเอกสารตามนโยบายวารสาร
- ไม่โฆษณาความแม่นยำที่ไม่ได้ backtest; ไม่สัญญาผลลัพธ์กับลูกค้า
- ความขัดแย้งทางผลประโยชน์: เปิดเผยแผนธุรกิจในต้นฉบับ
