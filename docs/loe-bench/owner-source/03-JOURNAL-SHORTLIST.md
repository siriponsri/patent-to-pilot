# 03 — รายชื่อวารสารที่เสนอ (Journal Shortlist)

**คำเตือนสำคัญ**
- ตรวจแล้วเฉพาะว่า "วารสารมีอยู่จริง" (ชื่อ, ISSN, ผู้จัดพิมพ์, สถานะ OA จากฐานข้อมูลวารสาร) **ยังไม่ได้ตรวจ quartile (SJR/JCR), Impact Factor, APC, ขอบเขตล่าสุด, และความเสี่ยง predatory** → ต้องตรวจเอง (Scimago: scimagojr.com; JCR; เว็บวารสารหมวด Aims & Scope) และตรวจว่ามหาวิทยาลัย/KMITL รองรับ APC หรือไม่
- วารสารไม่ได้ "ให้ผล outstanding" ผลต้องมาจากงานเรา เกณฑ์เลือกคือ **ความเหมาะสมกับประเภทผลงาน** และวารสารที่เคยตีพิมพ์งาน generic-entry อยู่แล้ว
- ไม่มีวารสารใดรับประกันการตอบรับ

## การจับคู่ผลงาน → วารสาร
| ผลงาน | ประเภท | ลำดับที่เสนอ |
|---|---|---|
| IS2 หลัก: method + benchmark + prospective Track A | method/outcome | Tier 1 (JAMIA / J Biomed Inform / AIM) → Tier 2 (Value in Health / CPT) |
| IS2 ถ้าผลบวกชัดและตีความเชิงนโยบายได้ | outcome | Tier 2 |
| Dataset descriptor ของ LOE-Bench (ผลลบ/เป็นกลางก็ตีพิมพ์ได้) | data | Scientific Data |
| IS3: คาดการณ์ remaining effective exclusivity ณ วัน launch | forecasting | Tier 3 / Value in Health |

## วิธีตรวจก่อนส่ง (ทำเป็นเช็กลิสต์)
1. ค้นชื่อใน Scimago → จดควอร์ไทล์ในหมวดที่ตรงกับเรา (ปีล่าสุด)
2. อ่าน Aims & Scope และ Author Guidelines → ตรงกับงานแบบ benchmark/method หรือไม่
3. ดูบทความ 5–10 เรื่องล่าสุดว่าประเภทคล้ายกันไหม
4. ตรวจ APC และนโยบาย data/code availability
5. ตรวจว่าอยู่ในดัชนี (Scopus/WoS) และไม่อยู่ในรายชื่อต้องสงสัย
6. ตรวจนโยบาย preprint และ preregistration
