# Thai operator prompt packet

The blocks below are ready to paste into approved interfaces. Use the three unchanged attachments specified in the private study inventory. Rename copies to A.pdf, B.pdf and C.pdf when the interface permits it, or record the visible equivalent names. Use a fresh chat or notebook with only the approved packet. This is exposed practice. The fixed few-shot examples are invented training material from unrelated families. Keep adjudication and source crosswalks away from the operator.

Start the proposed ten-minute clock when the operator opens the prepared packet. End at submitted answer, including import, wait, citation inspection and corrections. Record preparation, tool, visible mode, start, finish, any import or citation failure and prompts separately from the answer. For the zero-shot condition paste the first block, then the issue. ## Shared checklist

```text
อ่านเฉพาะเอกสารที่แนบ แล้วตอบเป็นภาษาไทยว่าหน่วยงานวินิจฉัยเรื่องที่ถามไว้อย่างไรในขณะนั้น

1. ระบุเลขหนังสือหารือ เลขความเห็น และหน่วยงานผู้ออกความเห็น
2. สรุปคำตอบของหน่วยงาน แยกจากความเห็นของผู้หารือหรือหน่วยงานอื่นที่ถูกอ้างถึง
3. ไล่ตรวจเงื่อนไข ข้อยกเว้น หรือลำดับขั้นที่ทำให้คำตอบเปลี่ยน ให้ระบุทีละข้อ
4. หลังข้อสรุปและแต่ละเงื่อนไข ระบุชื่อไฟล์กับหน้า PDF หรือย่อหน้าที่กดเปิดตรวจได้ ถ้าใช้หลายตอนร่วมกันให้ระบุทุกตอน
5. ถ้าหลักฐานไม่พอ ให้บอกว่าส่วนไหนยังตอบไม่ได้และต้องตรวจอะไรเพิ่ม อย่าเดาว่าปัจจุบันใช้กฎเดียวกัน
```

## Fixed examples for few-shot only

```text
สองตัวอย่างต่อไปเป็นเอกสารสมมติ ใช้ดูรูปแบบคำตอบเท่านั้น

ตัวอย่าง 1
ข้อมูล: เอกสารฝึก ก หน้า 1 อ้างหนังสือ ฝก 01 คณะกรรมการอาคารออกความเห็น ฝก 02 หน้า 2 ว่าเปิดห้องประชุมหลังเวลาปกติได้เมื่อมีเจ้าหน้าที่ประจำ และต้องแจ้งผู้ดูแลล่วงหน้าหนึ่งวัน
คำถาม: ขอเปิดห้องประชุมหลังเวลาปกติได้หรือไม่
คำตอบ: หนังสือ ฝก 01 ตอบโดยคณะกรรมการอาคารในความเห็น ฝก 02 (เอกสารฝึก ก หน้า 1) เปิดได้เมื่อมีเจ้าหน้าที่ประจำและแจ้งผู้ดูแลล่วงหน้าหนึ่งวัน (เอกสารฝึก ก หน้า 2)

ตัวอย่าง 2
ข้อมูล: เอกสารฝึก ข หน้า 1 อ้างหนังสือ ฝข 01 ประกาศ ฝข 02 ของฝ่ายบริการห้องสมุด หน้า 2 ระบุว่ายืมเครื่องอ่านได้เฉพาะในอาคาร ไม่มีรายละเอียดเรื่องการจอง
คำถาม: นำเครื่องอ่านออกนอกอาคารได้หรือไม่ และต้องจองล่วงหน้ากี่วัน
คำตอบ: ฝ่ายบริการห้องสมุดตอบในประกาศ ฝข 02 ซึ่งอ้างหนังสือ ฝข 01 (เอกสารฝึก ข หน้า 1) ใช้เครื่องอ่านได้เฉพาะในอาคาร (เอกสารฝึก ข หน้า 2) เอกสารชุดนี้ยังไม่พอให้ตอบจำนวนวันที่ต้องจอง ควรขอระเบียบการจองจากฝ่ายบริการห้องสมุด
```

## Identical issue

```text
ตามหนังสือหารือของสำนักงานคณะกรรมการอาหารและยา ที่ สธ ๐๘๑๒/๕๑๔๘ ลงวันที่ ๒๔ มิถุนายน ๒๕๓๙ กระทรวงสาธารณสุขจะกำหนดให้ผู้รับอนุญาตผลิตยาแผนปัจจุบันแสดงชื่อสามัญทางยาในรายการชื่อยาบนฉลากและเอกสารกำกับยาได้หรือไม่ และความเห็นในขณะนั้นระบุวิธีหรือเงื่อนไขไว้อย่างไร
```
