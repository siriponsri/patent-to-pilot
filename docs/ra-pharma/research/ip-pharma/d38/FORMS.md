# Matched paper forms v1

## Manual guidance checklist M1

Use FDA context C2. Read the inventory and record the following checks in order. Mark each item present or missing, enter the source and locator, and keep unresolved details explicit.

- Confirm the applicant, proposed product, US reference, review question and jurisdiction from the request.
- Confirm proposed and US reference lot identities and the structural record.
- Check the direct functional comparison for issuing owner, edition, product/lot pairing, method, reported observation and exact locator. Bind the observation to the report.
- Check whether any supplied literature addresses a different proposed product. Record what it supports for this item.
- Pick the routing disposition under the shared rules. Write the specific evidence request or report handoff. List unknowns and any unsupported claims in the completed form.

## One-row evidence record E1

Use FDA context C2 and the same reads and routing rules. Fill a single row with all fields. Enter a source and locator for each binding. Mark missing fields and unresolved details explicitly.
