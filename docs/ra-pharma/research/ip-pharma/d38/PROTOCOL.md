# D38 prospective protocol v1

27 November 2026. The [owner decision and prior impact review](https://github.com/siriponsri/patent-to-pilot/blob/7767994c0877933310a1109b165f19a60ffe1608/docs/ra-pharma/ip-pharma/D38-IMPACT-REVIEW.md) release one paper exercise following the [D36 recommendation](../d36/RECOMMENDATION.md).

## Task and inputs

For an internal US CMC document review, decide whether the fictional applicant's evidence on afucosylation and Fc-mediated function can proceed to scientific review. Use exactly inventory A and inventory B. Both contain the same request, structural summary and public context. B adds only the attributable functional report. These synthetic snapshots are exposed development material.

Each form receives the same inventory index and only its listed files. No cross-inventory carryover of attachments or previous outputs. The single executor follows the same source order in every cell: inventory, request, structure, context, functional report if listed. The executor manually fills the versioned checklist or one-row form. Run checklist A, row A, row B and checklist B in that order to vary first form by inventory. The executor also authored the inputs and necessarily knows the cases. The comparison is open and susceptible to recall and carryover. Keep the assessment key outside the inventory indexes and form instructions. The key is accessible to the author and does not confer blinding. No further source acquisition.

## Common decision rules and scoring

Check subject, intended reference, lots, method identity, reported observation and exact locator for the direct functional comparison. Carry the structural report locator and its role. Treat literature as context for the question. Route an attributable comparison to scientific review for assessment of adequacy, risk and interpretation. If the attributable comparison is missing, give the owner of that evidence a specific request and retain unknowns. These routing decisions cover evidence availability only.

Assess each cell on four required conditions. A pass requires all four.

1. Take the action specified by the separate assessment key.
2. Supply the precise request or the complete trace to the report that justifies the action.
3. Preserve applicant/reference, lot, method and observation attribution, including explicit unknowns, and distinguish structural and external evidence from the applicant functional result.
4. Keep clinical, scientific and regulatory conclusions out of the disposition. Record any unsupported claim.

Compare omissions, wrongful upgrades, source access and effort. Treat equivalent decisions with equivalent traceability as a tie and retain the checklist. An unsupported upgrade, unexplained difference or consequential omission stops advancement. A difference favoring the evidence row with matched inputs needs independent Planner review before any further work. This four-cell check estimates neither workflow effect nor accuracy in practice.

## Caps and integrity

Four manually completed cells, one fill per cell and one post-fill audit against the assessment key. Read at most the five listed items per cell, counting the inventory index. Record actual reads, deviations, retries and costs. Stop on a digest mismatch, unexpected input, missing provenance or access outside the envelope. Retain any attempted outputs and report cells left unrun. Zero incremental service spend, external requests for evidence, participants, extra agents, inference runs, protected test reads, real applicant data, experimental biology, Product changes and B2–B4 work. Git publication is the sole planned network activity after the freeze. Full suite is outside this documentation-only exercise.

The [SHA-256 manifest](SHA256SUMS.txt) binds the LF bytes of both inventory indexes, their sources, the forms, this protocol and the separate assessment key. Verify the commit and manifest before starting.
