# D36 prospective desk review

Authority is the [27 November dispatch](https://github.com/siriponsri/patent-to-pilot/blob/8c19ea67e2d4ff15f4613e875cdf01bcc8fb259d/docs/ra-pharma/ip-pharma/D36-DISPATCH.md). Scope and decision rules were recorded before source collection.

- Screen one US generic formulation/administration limitation and approved commercial alternatives, one US biosimilar comparator (CT-P10), and one US Medicare Part B biologic class with a Thai official-source feasibility check. Prefer rituximab for the market case if payer data identify it with a reproducible unit and denominator.
- Advance one operator decision only if it has a named operator, a current alternative, a primary witness germane to that decision, and a reversible test with a specified outcome that changes the decision. Record the strongest contrary observation for each. A marketed or labeled workaround can close a broad formulation gap. Missing Thai utilization and payer denominators park Thai sizing. Public comparator evidence can define a missing-evidence review task when it cannot justify advancing a new candidate. Rank by decision readiness under these rules, with no numerical score or commercial extrapolation.
- Inspect publication-level rights and visible notice surfaces before substantive use. Use stable public links and bibliographic facts when permission is uncertain. For an express restriction, stop at the notice, retain only permissible discovery metadata and access disposition, and create no source copy, extracted text, scan, digest of restricted contents, or derivative. Use rights-cleared public views for verification with brief factual paraphrases. Record unavailable hashes for transient views and retain no source payloads. No login, gated terms, uploads, paid services or outreach.
- First exercise the rights stop path on a synthetic notice with a sentinel payload. Acceptance requires zero payload accesses and zero retention, extraction, or marker scan calls on that branch. Record the case and result in the receipt. This is an intake check. The primary evidence review is manual desk research.
