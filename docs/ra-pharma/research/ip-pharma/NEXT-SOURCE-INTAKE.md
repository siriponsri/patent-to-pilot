## Proposed execution contract

Identical input per matter includes the exact FDA row key, as-of snapshot, jurisdiction, a single specified product evidence gap, relevant grant and cached ancestor locators, and the same source cards (issuer, edition, document type, release/availability and visible metadata). A label and an FDA chemistry review are separate actions. A filed record or Thai status lookup is a separate future track. The strongest fixed policy opens label first for marketed form/strength and public label statements, chemistry first for core composition, manufacture or quantitative controls, and prioritizes the first unmet material item in claim order for mixed gaps. Within the same role, prefer the most recent eligible edition at the fixed review date, then ascending source ID. A candidate uses observable metadata and applicability to rerank the same two sources. Equip both with the same witness verifier and abstention rule.

At most three enrolled matters, one charged source open per arm per matter, one common index of source headings/metadata, at most 16 MiB per artifact, 45 wall seconds per arm per matter, zero paid calls. Use the same extraction and finalizer, with up to three bounded cited passages and a supported/unknown finding. Record actual bytes, pages, CPU/wall time, acquisition failure, route taken and raw locators. Archive input bytes and make no network requests during scoring. Separately and blindly score one primary target statement per matter for complete, correct and correctly scoped evidence by permitted witness. A missing key stays unknown. Also report per-case unsupported issuance, abstention and action differences. One small DEV batch can establish engineering discrimination only. Any policy execution or score remains on HOLD until exact review with a pinned packet and independent key.

PatentAgentBench's FTO subset measures known-patent retrieval for selected cases, while PatentFinder addresses a molecule-to-claim task. These references help define competitor scope. Priorbit and Chemical Patent Analysis already expose patent search or claim-evidence workflows. A useful local result has to beat the strong fixed routing on these same pinned facts.
