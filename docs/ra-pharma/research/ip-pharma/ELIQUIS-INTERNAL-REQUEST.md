# ร่างบันทึกภายในเพื่อขอหลักฐานเพิ่มเติม

**สถานะ ร่างสำหรับตรวจทานภายใน**

**ผู้ส่ง** ทีมวิจัย Patent-to-Pilot

**เรียน** ทีมทรัพย์สินทางปัญญาและฝ่ายทะเบียนยา

**เรื่อง** ขอข้อมูลสิทธิบัตรไทยและหลักฐานผลิตภัณฑ์สำหรับทบทวน ELIQUIS SPRINKLE 0.15 mg

**วันที่อ้างอิงการตรวจ** 26 พฤศจิกายน 2569

**อ้างถึง** FDA NDA 220073 ผลิตภัณฑ์ 001 และ US11896586B2 ข้อถือสิทธิ 45

จาก Orange Book ฉบับที่เก็บไว้ พบรายการสิทธิบัตรสหรัฐฯ ดังกล่าวสำหรับผลิตภัณฑ์ตรงตามเลขอ้างอิง ฉลาก FDA ระบุ apixaban 0.15 mg ต่อแคปซูล ส่วนรายงานคุณภาพระบุว่าในแคปซูลมีเม็ดบีดและปกปิดข้อมูลบางช่อง ขณะนี้ยังยืนยันเลขคำขอ ข้อถือสิทธิ หรือสถานะทะเบียนสิทธิบัตรในประเทศไทยไม่ได้

ขอให้ช่วยตรวจและส่งข้อมูลเฉพาะส่วนที่ได้รับอนุญาตให้ใช้ภายใน ดังนี้

1. เลขคำขอหรือเลขประกาศโฆษณาในประเทศไทยที่เชื่อมโยงกับ WO2019204193A1 หรือ PCT/US2019/027456 พร้อมแหล่งที่ใช้ยืนยันความเชื่อมโยง
2. สำเนาข้อถือสิทธิไทยฉบับที่เกี่ยวข้องและหลักฐานสถานะจากกรมทรัพย์สินทางปัญญา ระบุวันที่ตรวจสอบและเลขอ้างอิงเหตุการณ์ในทะเบียน หากยังตรวจไม่ได้ โปรดแจ้งรายการหลักฐานที่ขาด
3. เอกสารที่ระบุรุ่นผลิตภัณฑ์หรือรุ่นการผลิตและยืนยันได้ว่าองค์ประกอบอยู่ส่วนใดของเม็ดบีด พร้อมร้อยละ apixaban โดยน้ำหนักของแกนที่ผ่านการเคลือบ และข้อมูลกระบวนการที่จำเป็นต่อการตรวจข้อถือสิทธิ ขอเฉพาะส่วนที่เปิดเผยหรือได้รับอนุญาตให้แชร์
