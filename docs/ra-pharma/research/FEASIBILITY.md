In a future revision task, invalidate changed support links and flag the affected sentence for verification, permitting independent alternative support. ## Bounded review proposal

Freeze the input split, evaluator, prompt, budgets, winner rule and ledger before any outputs. Run baselines first. Proposed first batch has one unchanged-source hypothesis. Freeze one short-packet cap for all arms, with zero paid spend or GPU rental, at most two calls per issue, 16,384 total input tokens including repeats and examples, 2,048 total output tokens, and 120 wall seconds per issue per architecture arm. Measure overhead within those limits. Treat a cap breach as a recorded outcome. These numbers require feasibility and owner review before any dispatch.
