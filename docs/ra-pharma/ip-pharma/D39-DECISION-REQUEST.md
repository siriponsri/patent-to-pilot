Planner verifies the source locator behind each promoted claim and records accept, correct or park before releasing the next batch. Resume a failed batch from its last verified receipt. A tie retains the incumbent. A blocked lead can be replaced within the same track and cap; record the reason and original outcome. If no credible lead survives, release the negative portfolio handback early. Do not manufacture batches or rerun D38 on cosmetic changes.
