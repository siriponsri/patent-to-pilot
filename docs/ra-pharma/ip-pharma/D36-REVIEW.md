**Advance a single evidence-readiness question to owner decision.** A biosimilar CMC lead must decide whether a rituximab applicant has supplied a traceable comparison of afucosylation and Fc-mediated activity or whether to request missing results. The manual FDA-guidance checklist is a credible competitor. Actual demand, time saved and comparative performance remain unknown. **Proposed smallest test, pending release.** Use two synthetic attachment inventories. In the first, the US-reference functional report is missing. In the second, both products, lots, method, result and source locator are attributable. Compare the current checklist with one evidence row on the same inputs. Require the missing-data request in the first and readiness for scientific review in the second. Prefer the existing checklist if both dispositions and traceability are equivalent. Any promotion of published CT-P10 results to applicant evidence disqualifies the new workflow. The desk check, operator validation, B2–B4 and Product implementation are NOT_RUN.
