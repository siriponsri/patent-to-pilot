# US claim dependency pilot

## Selection and freeze

This second exposed pilot follows the first FDA pilot. Take the first cross-product example returned by the independent audit, chosen by sorting the apixaban rows by target key, source key, patent number and row number. The selected US identifier is 11896586. This selection is post hoc with respect to the FDA pilot. All dependency rules below are frozen before accessing its patent text. The question tests the patent specialist on its actual pharma dossier.

Retrieve the Google Patents HTML for US11896586B2 and freeze its bytes before extracting claim text. Stop if identity, grant kind or a complete numbered claim section cannot be verified. Store the source outside Git. On this one document only, check every claim with a single explicit English reference of the form "claim N". Assess the requested set of ancestral claim numbers, excluding the claim itself. Independent claims have the empty set. Mark ambiguous, range, multiple, missing, cancelled or forward references unjudged and propagate uncertainty to descendants. Every method sees the same normalized claim rows and document version.

Compare three deterministic readings. Flat returns an empty ancestor set. Direct returns its explicit parent only. Walk follows the same explicit parent relation to the root. An auditor transcribes the direct parents from the displayed text, derives expected ancestors and compares exact sets. Report coverage, unjudged, each method's exact-set agreement and one multi-hop witness if available. Report equality openly if this grant is shallow. A cached graph walk with the same parents has identical answers to walk; it is the strong architecture control. This is structural engineering on an exposed US grant, with no model, judge, significance test, infringement classification or Thai legal-status result. Preserve source locator, version, hash and any failed retrieval. No replacement document or parameter search.
