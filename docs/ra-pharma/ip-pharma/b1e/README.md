## Data and review before selecting products

FDA's [PDUFA report](https://www.fda.gov/media/191112/download) distinguishes AP approval from TA tentative approval. Match only ORIG/AP in the original submission table; a later strength requires separate coverage proof. Dosage-form spelling follows [Appendix C, page C-1](https://www.fda.gov/media/71523/download?attachment=), September 2026, combined with a sole ORAL route.

The [FDA UNII August 4 release](https://precision.fda.gov/uniisearch/archive) provides official, common, systematic and display names and standard InChIKeys. It does not itself provide the active-moiety relationship. Use the explicit ACTIVE MOIETY direction in the [openFDA substance export](https://open.fda.gov/apis/other/substance/), export date November 24. Accept exactly one identified target, including an explicit self-reference. Use a complete InChIKey match of the target to a record explicitly classified as Small molecule by [EMBL-EBI ChEMBL](https://www.ebi.ac.uk/chembldb/), ChEMBL 37, four API pages from the molecule endpoint filtered to max_phase=4. The 3,475 distinct molecule IDs cover the curated approved subset and do not exhaust all possible ingredients. ChEMBL data are CC BY-SA 3.0. Local attribution and source snapshots are retained. FDA/UNII local factual metadata use only; external redistribution and upload rights remain unassessed. Keep all raw source and dictionary bytes outside Git.

The selector matches only an unambiguous exact normalized alias and all components of a combination. Class or moiety uncertainty is an explicit pre-group exclusion. Historical exposure uncertainty alone stays eligible. The exclusion alias file includes all matching UNII seed identities and their documented active-moiety relations independently of the ChEMBL classification. Exact aliases in the names release are excluded even when positive classification is unavailable. The exclusion seeds are the registered six ingredients, previous named exposed ingredients, NDAs 220073, 220963, 221109 and 219379, and confirmed US grant identifiers appearing in safe project records. Exact listed grant overlaps with those seed keys are also excluded. EP families, publication aliases and product-demo pregrant IDs without a verified US grant mapping remain unresolved. No worldwide family linkage is inferred.

The local synthetic checks exercise original/supplement filtering, conflicting dates/identities, duplicate listed patents, exact product join, a later strength without inferred scope, combination aliases, missing classification, ties and truncation to 24.
