# Product executor brief

Use Claude Sonnet 5.5 medium in a separate checkout of `product/ra-pharma`. Read the [board](../MASTER-PLAN.md), [contract](../EVIDENCE-CONTRACT.md), [lane handoff](HANDOFF.md) and [S4 local workflow](../../evidence-scope/receipts/S4-product-release.md). Build one Thai-first, end-to-end local Windows dossier for a fictional taste-masked tablet. Use cleared public sources and explicitly synthetic applicant documents. Record sources, editions, rights, locators and digests.

1. **P1 · Open the dossier.** Reuse the existing launcher, SQLite store, source viewer and citation graph. Use one dossier ID with applicant, product, market and as-of date. Persist product facts separately from external examples. Surface the three outputs in a single workflow.
2. **P2 · Read the patent.** Title and abstract support discovery; description and claims have distinct roles. Use the existing US20120276199A1 display family to follow claims 15 → 2 → 1 and 18 → 17 → 1. Produce an element-by-element comparison, including unknown product facts. Record publication type, family, jurisdiction, legal-status source and date or the outstanding check. A US application alone leaves the Thai FTO assessment unresolved. Save the result for professional review.
3. **P3 · Build a registration checklist.** Link a narrowly scoped quality question to a versioned [Thai FDA / ASEAN ACTR and ACTD source](https://drug.fda.moph.go.th/registration-of-ordinary-medicine/actr-actd-2550). Keep guidance distinct from binding provisions. Read original Thai and English, apply country/date filters, and show the supporting applicant report or the exact missing attachment. Design the authority profile for foreign instruments; mark coverage by jurisdiction rather than implying worldwide validation.
4. **P4 · Read and draft correspondence.** Import a fictional request for information with known page layout. Identify document type, sender, addressee, number, date, reference, enclosures, signature area and the location/size of the Garuda emblem when present. Preserve page coordinates and uncertain readings. Distinguish an authority letter from a company's reply. Base the visual check on a versioned [official model](https://www.opm.go.th/media1/temp/pitthais/CentralReg/6govtdoc2526.pdf). Select the outgoing template by sender and authority. Produce an editable Thai letter, an enclosure list and an internal evidence view. Inspect the rendered page, typography, line breaks and placement. Leave issue, signature and submission to an authorized person.
5. **P5 · Demonstrate learning and hand off.** Implement a reviewable correction: reject a patent-example result as applicant data, propose a versioned reading skill, test it on a distinct development fixture and preserve the previous version for replay. Demonstrate before and after supplying an applicant report; show the changed sentence and unchanged patent evidence. Include a conflicting edition and a missing attachment. Verify the normal launcher, citation navigation, editable export, reopening both snapshots and backup/restore. Report which actions were deterministic, model-assisted or operator-reviewed. Run the full QA gate for code changes and document the command/environment. Deliver one owner walkthrough with exact paths and remaining gaps.

The acceptance demonstration uses display-only data. Keep the research labels, DAPFAM and PatEmbed outside the distributed product. Tool installs and project-local adapters follow the common board. A local demo earns a local engineering disposition; adoption, regulatory approval, external deployment and legal clearance require separate evidence.
