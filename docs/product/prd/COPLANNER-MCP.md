## M1 | What a caller can request

Publish a closed JSON Schema input and output for each tool. Proposed v1 limits below are engineering budgets to verify on Thai and English cases. Define a snapshot by immutable release ID, mode, ISO as-of date and horizon (12 or 24 months). Publish valid combinations in the tool descriptions or a bounded default discovery call. With no snapshot, `search_drugs` uses the explicitly named default released snapshot and returns its key and available choices. All follow-up calls require the selected key. Never silently substitute another release or horizon. Capacity is fixed at 0.20 for the registered queue. Keep dated method results distinct from the forecast cutoff. [MCP tools and output schemas](https://modelcontextprotocol.io/specification/2026-07-28/server/tools) · [PRD claims](PRD-MWD-v1.md#3-claims-the-product-may-make)

| Tool | Inputs beyond snapshot | Output inside the common envelope |
|---|---|---|
| `search_drugs` | Literal name or molecule key, 1–128 characters, optional language th/en, page | Matching keys, display names, dossier availability and snapshot choices. Stable name/key order. Empty matches are a successful empty page. |
| `get_queue` | Capacity fixed at 0.20, optional scope selected/all, page | Released rank, molecule key, horizon-specific score, inclusion flag, queue denominator and cutoff. Preserve published tie order and inclusion probabilities where supplied. |
| `get_dossier` | Molecule key, optional section from the seven schema IDs, optional claim IDs (1–20), language, page | Claims with IDs, state, kind, jurisdiction, time basis, localized text and resolved source references. Expose only claims valid for this view. |
| `get_sources` | Molecule key and optional 1–20 source IDs, page | Only sources reachable from visible claims or checklist evidence, with issuer, title, edition, public date, retrieval date, locator, URL and recorded SHA-256. A null upstream hash stays null. |
| `get_fto_checklist` | Molecule key, optional owner enum from schema, language, page | Task ID, role, agency, next question, lookup link and evidence references. Preserve unknown Thai status. Reading never changes checklist state. |
| `get_method_card` | Optional language | Named endpoint, horizon, capacity, numerator/denominator and unit from the receipt, H1 result, H2 failure, scope of the LLM comparison and Track A outcome pending. Cite the dated receipt locator for each statement. |

**Evidence that travels with the answer.** Require `api_version`, `release_id`, release-manifest SHA-256, `as_of`, `mode`, native forecast status, horizon, jurisdiction, published label and canonical bilingual disclaimer in every successful page, including empty pages. For Track A preserve freeze verification and the outcome-pending label. Populate the development disclaimer from reviewed release copy when absent in storage. Each factual row carries a scoped claim ID plus evidence ID, version and locator, or a typed queue-row, task or method-receipt reference where the source has no claim ID. Publish the artifact digest separately from a nullable upstream digest. Missing required provenance blocks that assertion. Generate `structuredContent` and a self-contained text fallback from one envelope. Repeat the notice and snapshot in the text and every independently retrievable resource. The client can still omit them from its prose. [MCP tools](https://modelcontextprotocol.io/specification/2026-07-28/server/tools) · [local evidence contract](COPLANNER-AI-PLATFORM.md)

**Bounds and errors.** Default 10 rows, maximum 25. Cap application inputs at 16 KiB UTF-8 and serialized tool results, including text fallback, at 64 KiB. Page at record boundaries, with opaque cursors bound to release, filters, language and ordering. Return a null next cursor at completion. Reject mismatched cursors and return a typed size error for one oversized row. Schema versions are independent of MCP revision and dataset version. Freeze v1 names and meanings, with a new major contract for breaking changes. Protocol errors cover malformed JSON-RPC, unknown method or tool. For bad tool arguments, unavailable snapshots, missing dossier or stale cursor return `isError:true` with stable reason, retryability and safe display text. Include the notice and resolved snapshot, or explicit nulls for an unresolved selection. An unknown evidence state is valid data. Transport failures have no dossier result. [MCP error model](https://modelcontextprotocol.io/specification/2026-07-28/server/tools#error-handling)

**Tools, resources and prompts.** Use tools for searchable, paged and computed answers across the client matrix. Optionally expose the same immutable method card and manifest as named read-only resources for hosts with resource pickers. A prompt is a user-selected template and adds no required capability here. Declare only implemented capabilities. Publish fixed reviewed descriptions and `readOnlyHint:true`, `openWorldHint:false` for operations confined to the release, with `destructiveHint:false` and `idempotentHint:true` where supported. Enforce read-only access in the handlers. [Resources](https://modelcontextprotocol.io/specification/2026-07-28/server/resources) · [Prompts](https://modelcontextprotocol.io/specification/2026-07-28/server/prompts) · [MCP annotation semantics](https://blog.modelcontextprotocol.io/posts/2026-03-16-tool-annotations/)

## M2 | Transport and publication

**Pin MCP 2026-07-28**, the current revision on the review date. Modern clients can discover via `server/discover` and declare version, client identity and capabilities per request. One HTTPS `/mcp` endpoint accepts one UTF-8 JSON-RPC message per POST. Clients advertise JSON and event-stream in Accept. Return JSON for these bounded reads, or request-scoped SSE. Enforce matching `MCP-Protocol-Version`, `Mcp-Method` and applicable `Mcp-Name` headers against the body. Reject invalid supplied Origin with 403 and header mismatch with 400. Modern operation needs neither a session ID nor a GET stream. Test the SDK's stateless legacy path separately using 2025-11-25 initialize/initialized, list and call. For local stdio, reserve stdout for newline-delimited protocol messages and send diagnostics to stderr. [Version register](https://modelcontextprotocol.io/specification/versioning) · [HTTP binding](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports/streamable-http) · [legacy interoperability](https://modelcontextprotocol.io/specification/2026-07-28/basic/versioning) · [stdio](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports/stdio)

**One implementation.** The official Python SDK can serve stdio and is useful for B2 integration tests. For M1 ship one TypeScript server factory containing the schemas, operation handlers, envelope and projection reader. Attach Node stdio locally and Cloudflare's stateless `createMcpHandler` in the Worker. Pin compatible SDK/Agents versions. Cloudflare marks the Durable Object-based `McpAgent` deprecated. Generate M5 from this registry. Compare normalized results and definitions across transports, including the legacy path. [Python SDK](https://github.com/modelcontextprotocol/python-sdk) · [TypeScript SDK](https://github.com/modelcontextprotocol/typescript-sdk) · [Cloudflare handler and legacy option](https://developers.cloudflare.com/agents/model-context-protocol/apis/handler-api/)

**Release and hosting.** Build pre-indexed, field-allowlisted JSON shards from the reviewed Pages release, pin their digests and bundle the identical shards with both adapters. Test parity with the public website's visible forecast fields. Include linked evidence only after checking its time basis and publication cutoff. Exclude retrospective outcome claims, reveal-only sources, outcome-derived selection labels and links with reveal enabled. A queue entry may have no dossier. A release mismatch makes the snapshot unavailable. Bundling permits offline stdio and avoids fetching mutable Pages files per call. If measured size forces external assets, fetch only immutable paths from the pinned Pages origin, verify each digest before caching and reject redirects and caller-supplied URLs. Publish the website on the owner's Pages subdomain and MCP on the owner's Workers subdomain. The localhost AI gateway has no route from either. [Demo loader](../../../product/demo/README.md) · [Cloudflare workers.dev](https://developers.cloudflare.com/workers/configuration/routing/workers-dev/)

Workers Free currently allows 100,000 requests/day per account, 10 ms CPU per invocation, 128 MB memory, 50 subrequests/request and a 64 MiB uncompressed Worker. Record actual bundle size, cold start and CPU for the largest bilingual page. Anonymous read access is reasonable for public releases with no user-specific authority. Document the deliberate exception to the transport's authentication recommendation. Allow legitimate server clients without Origin, explicitly allow known browser origins and avoid wildcard browser permissions. Apply an early method/body limit, approximate per-location burst limit (proposed 60 reads/minute per transient caller bucket), and a shared per-location ceiling. Return 429 with Retry-After for application throttling. Client egress may be shared. Test that normal pagination passes. Watch account-level quota separately and keep Pages available during MCP exhaustion. [Workers limits](https://developers.cloudflare.com/workers/platform/limits/) · [rate-limit binding semantics](https://developers.cloudflare.com/workers/runtime-apis/bindings/rate-limit/) · [MCP transport security](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports/streamable-http#security--endpoint)

## Security and comparison evidence

Treat all returned titles, quotations and draft strings as untrusted data for the calling agent. Preserve source text and locators inside bounded data fields. Keep descriptions, examples, schemas and resource metadata under release review, hash the catalog, and require a reviewed diff on change. A caller should pin the server origin and approved tools, review catalog changes and avoid executing instructions in evidence. B5 can test correct containment and serialization. It cannot guarantee the behavior of an external model. Include a harmless instruction-like fixture in both a title and claim. [Greshake et al., indirect prompt injection](https://arxiv.org/abs/2302.12173) · [MCP tool security](https://modelcontextprotocol.io/specification/2026-07-28/server/tools#security-considerations)

Serve public identifiers and field projections only. No arbitrary fetch, filesystem access from arguments, writes, provider calls, email, credentials or access to the local gateway. Log aggregate calls, tool name, reason code, release and latency band only. Disable request/body and exception-payload capture, exclude raw IPs, URLs with queries, headers, query text and drafts from application/observability logs. Review the owner's Cloudflare logging settings and distinguish platform processing from application retention. [MCP security guidance](https://modelcontextprotocol.io/specification/2026-07-28/server/tools#security-considerations) · [Workers observability](https://developers.cloudflare.com/workers/observability/logs/workers-logs/)

Two external workflow comparators offer agent access. Patsnap's hosted MCP exposes patent search and analysis. BioMCP exposes regulatory labels and approvals using openFDA. Compare the ability to retrieve a dated source from an agent. Neither was run against MWD, and no performance or coverage ranking follows. [Patsnap MCP](https://open.patsnap.com/devportal/guides/mcp-overview) · [BioMCP data sources](https://biomcp.org/reference/data-sources/)
