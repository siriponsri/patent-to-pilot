# S1 prospective measurement packet, v1

Effective 2026-11-25, before any new ranking or outcome measurement. S3 implements and meters policies. The small, deterministic pilot supports controlled engineering comparisons. Its three reserved Thai source families cannot support a precise population claim.

## Material and separation

The research runtime receives only `runtime/<lane>/{requests,sources,units,edges}.jsonl`. Each request identifies one dossier by family ID. All six units of that dossier are indexed, including two supplementary distractors. This is bounded within-dossier acquisition. The supplied ordered seed has four units and counts as the first action. Every arm gets the same seed and eligible corpus for that request. Never mount the authoring module, evaluator or this packet specification in the policy process. Family, document and case IDs are join keys only and must not be policy features. Gold labels, state names and pair IDs exist solely under `evaluator/`. No optimizer, author or developer may use reserved DEV response traces to select an arm.

The first two independently authored subject families per language are assigned to proposal and selection respectively. Three subsequent distinct families per language are reserved for DEV. This is a fixed purposive assignment, not random sampling. Seed 20261125 salts opaque unit IDs, request IDs and arrangement within tied design positions. [Splits](evaluator/splits.jsonl) bind each text, paraphrase, template and any future translation to its ancestor. Demo families occupy the separate `demo-` namespace. English is an original transfer set, not a translation of the Thai cases. Authors wrote each scenario from scratch. All share the two-branch reference structure by design. Natural documents, independent annotation, deployment generalization and cross-language paraphrase equivalence have not been measured.

The attached full texts are the archival source. Each unit carries the source ID, version, UTF-8 source SHA-256, original locator, half-open Unicode code-point offsets and unit SHA-256. No PDF geometry is claimed. An edge identifies both units and quotes the source passage licensing that relation. In the product contract these map by meaning to source ID/version/hash, exact locator/offset and relation endpoints. Thai attachments and referenced rules can be distinct source IDs. Patent alternatives can occur in the same source. Conclusions require both the applicable clause and the referenced answer passage. Outcomes are exact authored text spans (or the English numeral word where appropriate); S3 emits a canonical short decision separately from user-facing prose. The unit corpus retains original text. Search normalization never substitutes for the original locator.

## Controlled cases and labels

Each of ten families has three user wordings (original, invariant paraphrase and changed scope), each under three designed initial rankings. An additional finite-dossier request asks for an unrecorded property. Present cases put the two compatible units first; displaced cases put the opposite branch first; outside cases present a cross-branch mixture with no complete assignment. The missing unit remains within the six-unit dossier. Invariance and scope-changing pair members share exactly the same source bytes and ordered pool. Selection of the opposite branch can change the pool-state label of the variant. Pair orientation alternates by state and family. Pair listings identify both directions. An original request can belong to two different comparisons; a request counts once in the primary estimate. Counts by split/domain/state and ordered ID-bearing files are pinned in the [manifest](manifest.json).

Each answerable label permits a complete set of cited units for one scope assignment. Required units bind scope plus the answer; both must support the same decision. An additional justified unit is allowed only if the same assignment explicitly permits it. Returned alternatives may be displayed separately. The scorer supports multiple acceptable assignments. Finite unanswerables cover only the supplied dossier. Ambiguous natural cases would receive UNADJUDICATED and a separate count. There are no natural cases, secondary adjudicators or unresolved author disagreements in v1. Ground truth derives from the authored references and request edits. No engine output, LLM grading or external professional assessment contributed to it.

Rank by a documented direct reference connecting both units, then number of matched request conditions, then sum of BM25 scores, then sorted unit IDs. Check references in the ordinary source graph only. Keep the existing leading assignment when its rank tuple (excluding ID) ties the winner. Rerank never searches beyond the current pool. This is a deterministic adaptation of fixed-pool compatibility ranking. |

Reranking cannot trigger more acquisition through compatibility in this controller. |

If the graph and text still fail to support an answer, abstain. The ablation disables only this action-selection signal. |
