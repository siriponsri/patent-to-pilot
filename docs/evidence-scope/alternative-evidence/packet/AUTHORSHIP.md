## Annotation contract

Text in `sources` is the packet's canonical text. Controlled source text joins authored units of each publication revision with two LF characters and ends with one LF. The natural receipt describes the excerpt assembly. Unit offsets count Unicode code points from zero and end just before the next character. Source and unit digests hash UTF-8 text bytes with no BOM. All annotations are in the language of the source except normalized field names. Question topics are short issue names. Phrase-level normalization maps questions such as “กี่โมง” to `เวลาส่งฟิล์ม` and “how wide across” to `shaft diameter`. Condition values and answers are literal source phrases. The verifier checks that condition strings are also literally present in the associated question. A null answer indicates the unit supplies context, a condition or a reference.

Each typed edge is origin-to-target. The basis is a literal quote identifying why opening the target is required. Retained-scope edges cross editions only where the later fictional text expressly retains the identified earlier clause. Superseded answer clauses are edition-specific roots and their replacement statements do not contribute the old answer to the new chain. Patent-style inheritance follows explicit parent direction. Claim siblings that only share a parent cannot borrow one another's scope. The initial seed order is fixed per family and shared within each pair. The order of seeded and missing members varies. Equivalent assignments in `ae-th-seed-storage` require a complete instruction and its shared definition.

Witness arrays list the root first. `required` and `permitted` are identical for each assignment because the fixture defines exact chains. Optional UI display of unused evidence belongs outside the assigned support. Equivalent authorized chains appear as separate assignments. Each `changing` pair varies one public condition and changes the witness assignment, the literal answer or both. An `invariant` pair preserves the conditions, assignments and answer. The closed controlled family graphs ground the finite scope combinations. Natural unknowns use `UNADJUDICATED`.
