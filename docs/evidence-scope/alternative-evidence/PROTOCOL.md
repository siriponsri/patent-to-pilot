## Target and falsifier

When two possible chains give the same literal conclusion but use different witnesses, can preserving their requirement-to-span bindings help choose a better next passage under the same access and ranking budget? The experimental unit is one adjudicated, answerable Thai request in the new controlled packet. Success requires the canonical conclusion and all required compatible witnesses in one permitted assignment. Evidence must also pass trace, provenance, scope and budget validation. The primary estimand is the case-weighted paired success difference between the assignment selector and the premise-directed local control. A single family may supply sibling wording, alternate validity conditions and more than one ordering. A family is the unit of uncertainty.

The generic choice to retrieve a premise that separates candidate answers is established prior art. The narrower, falsifiable intervention supplies differences between exact scope bindings and reference obligations to the next-opening decision. A gain with identical sequences under a strong prior-method adaptation is impossible by construction. If the tracked sequences or outputs are materially indistinguishable, or the observed gain lacks the prespecified same-answer or ablation signal, limit the result to diagnostic evidence. No priority, real-world prevalence or product effectiveness conclusion is authorized.

## Common state and release rule

1. Runtime input includes a fixed ordered seed, original source snapshots, span identities, query wording, neutral topic and condition keys bound to that wording, and source-stated typed edges. A corpus family has 4–12 units and at most 24 directed edges. Reference extractors are fixed source annotations or controlled authored fields. They are neither a learned natural-language parser nor an answer oracle. Their accuracy outside the packet is unmeasured.
2. Seed opens exactly the supplied 2–5 IDs. The first metered rerank, and each later metered rerank, inspect the same current pool and outgoing edge records available to all arms. They construct a prospective assignment per visible topic root. Traverse only opened units along source-licensed edges. Record each condition's inspected bindings, conflicting conditions, possible conclusion, unseen required edge targets, and exact source/version/span for the inspected portion. A link exposes its ID, role and licensing quote from the origin. A link cannot expose target wording, scope values or the target's outgoing links before that target is opened.
3. Every documented outgoing obligation of an accepted proof must be satisfied. A mismatched required condition or conflicting conclusions excludes a path. A missing condition, missing target or missing conclusion remains unresolved. Proofs may cross sources, versions and branches when an explicit typed link permits that path. A private sibling with no licensed path cannot contribute a fact. The system only attests to the evidence in the allowed packet and the unresolved obligations it observed.
4. The identical compatibility ranker puts viable before conflicting assignments, then complete before partial, then fewer unbound conditions and obligations, then larger summed original-question BM25, then ascending opaque root ID. Source/edition holdings are never used as a label. Exact role types and content digests appear in the trace.
5. All arms use the same release guard. It requires at least one complete viable chain, no unresolved viable chain, and agreement among viable conclusions. Return the leading complete chain with its exact witnesses, provided it fits the output ceiling. Keep preserves the leading seed-chain order. An admissible in-pool change is rerank. Retrieval that fills a chain is acquire. If the guard cannot pass within the budget, abstain without affirmative support. An abstention is a bounded statement about this search, not a corpus-wide or legal conclusion.

The prototype represents alternatives as distinct topic roots and treats each root's typed outgoing obligations conjunctively. It requires annotated applicability facts. Free-form rule interpretation, disjunction within a single annotated root, and inference of operative dates from bare historical text are outside the measured interface.

## Matched selectors

| Arm | Information entering the next-opening decision |
|---|---|
| `assignments` (nominated) | Each viable root is a separate binding set even when its current conclusion equals a rival's. Given an unopened licensed target, maximize the number of separated root pairs `m × (N − m)` where `m` roots have that obligation and `N` are viable. Tie-break by gate role, earliest compatible rank, then ascending opaque target ID. This is a deterministic structural proxy, with no simulated answer values or probabilities. |
| `premise` (single primary control) | The strongest local adaptation here of the competing-answer, premise-directed approach. Group known equal literal conclusions together and keep unresolved-answer roots distinct. A target is a candidate premise shared by the groups with an observed reference to it. Maximize the analogous separated answer-group pairs, then gate role, rank position, opaque target ID. It can open the same explicit references, reads new premises after every opening, and can use a newly exposed next reference. It uses the identical local corpus, graph, ranker, trigger, ingestion, final guard and caps. This is an adaptation, using a deterministic query/graph adapter instead of the original model and prompt. |
| `no_disagreement` | Remove only the split term from the next-opening priority by setting it to zero. All active assignments, candidate targets, neutral tie-breaks, ranker, recorded state and final guard stay available. |
| `follow_reference` | Follow the earliest viable ranked pending reference with opaque-target tie-break. It can chain multiple visible links as new evidence arrives. |
| `coverage` | Prefer a prospect cited by the largest number of viable paths with at least one uncovered condition. Tie-break by shared gate role, compatibility rank and target ID. It receives the same scopes, facts and options. |

A gate role is applicability, amendment or qualification, then dependency, then ordinary reference. All selectors may choose a known reference or request an untargeted acquisition. The same retriever scores all eligible dossier IDs using BM25 on NFKC, casefolded, whitespace-collapsed overlapping character trigrams of locator plus text. Use Okapi k1=1.2 and b=0.75 and one contribution per distinct query trigram. A chosen licensed target ranks first. Among other unopened candidates, use descending BM25 and ascending ID. Only the selected unit is opened. If no viable prospect is available, use the ordinary lexical ranking. The primary contrast therefore changes selection, while the shared tools, decision threshold and verifier remain fixed. Fixed-pool Entropic Claim Resolution is NOT_RUN.

## Resource accounting and integrity

One local serial standard-library Python policy process, no model, token use, remote host, API, or paid spend. Offline ingestion and index construction have their own byte, wall and CPU counters. Launch wall time covers process startup, but whole-process CPU outside timed regions is unmeasured. Each seed inspection, full in-pool assignment rerank and acquisition costs one action. An acquisition meters every lexical candidate scored and one opened unit; a rerank meters repeated inspections of its current pool and the number of outgoing graph edges read from that pool. Graph walking and the full assignment sort occur only inside rerank. Next-target computation uses the metered snapshot and has its own planning duration, recorded within the acquisition. No action reads the text of an unopened unit outside the shared acquisition. Timestamp and processing budgets use monotonic elapsed and CPU clocks.

Per request caps are 8 actions including seed, 12 candidate inspections per operation, 96 total candidate inspections, 96 outgoing-edge reads, 8 returned units, 30 seconds and 0 model tokens. The alternating schedule admits at most three acquisitions because a final rerank is reserved. Worker capture additionally times out after 120 seconds per language or natural diagnostic lane. Record incomplete, failed, duplicate, invalid and missing trials. Score invalid/missing answerable or finite trials as failure and retain their errors. An overrun or invalid capture bars a supported-gain disposition.

The orchestrator first checks snapshot and split invariants. It projects only runtime schema fields and stages a separate temporary processor directory containing the worker and runtime JSON. The scorer, labels, pair/judgment fields and manifest stay in the process that validates captures, never in the worker's input. This is logical input isolation, not a sandbox. Every original input, fixture, cross-language family, case count and source right is separately pinned. Natural records with unsettled interpretation are unadjudicated and appear in separate denominators. See the packet's provenance file for who authored and adjudicated each lane.
