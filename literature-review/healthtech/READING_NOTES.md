## สิ่งที่หลักฐานรองรับและยังไม่รองรับ

Bridge กำหนด task ใกล้ที่สุด แต่ release audit ใน pack เป็น source-reported finding ที่ไม่ได้รันซ้ำใน migration นี้ ต้อง reconcile 672/79 กับ 585/74 และ paper 585/88 ก่อน main study ไม่ใช้ sampled unlisted pairs เป็น verified negatives และไม่ใช้ KG predictions เป็น independent reference

SciFact เป็นส่วนประเมิน evidence ตาม original task ไม่ใช่คำตัดสินว่า patent ครอบคลุม device หรือ dossier ทั้งฉบับถูกต้อง [official README](https://github.com/allenai/scifact) ระบุ test labels ไม่เปิดให้คำนวณ local paper test scores ต้องใช้ official evaluation route หรือสร้าง frozen held-out design ที่ระบุว่า adapted; train/dev labels ที่เปิดอยู่ยังต้องแยกจาก final evaluation

Novelty ยังไม่ยืนยัน: P14–P19/P23–P24 ครอบคลุม routing, adaptive acquisition, cost-aware selection และ stopping อยู่แล้ว ส่วน P01/P13 ชน domain และ evidence granularity Contribution ที่อาจมีคือ patent-specific cohort/incomplete-judgment/group/cost findings จากการเปรียบเทียบจริง ไม่ใช่การมี agent หรือ citation ใน output

Paper rights, code rights และ dataset rights อยู่คนละระดับ ดู [supplemental data proposal](../../docs/healthtech/research/SUPPLEMENTAL_DATA.md) ก่อน acquisition/redistribution ไม่มี paid experiment, publication-ready result หรือ clinical/legal validation เกิดขึ้นจาก notes ชุดนี้
